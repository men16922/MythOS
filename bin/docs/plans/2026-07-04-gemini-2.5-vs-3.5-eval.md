**턴 2 — '내밀어진 손' 동일 비트:**
- 2.5: "바이크의 엔진 소리가 빗소리에 섞여 낮게 울리고, 멀리서 감시 드론의 탐조등이 골목을 느리게 훑으며…"

## 컨텍스트 캐싱 — 진단 정정 (2026-07-04 저녁, 웹검색+재실측)

- **"암시적 캐싱 미작동"은 오진**이었다: 캐시 쓰기 **전파에 수초~수십초**가 걸린다. 2초 간격 3연속은 0이지만 **20초 간격이면 2.5·3.5 모두 적중**(동일 7.6k 프롬프트: 2.5=7146, 3.5=6117 캐시). 실제 플레이 턴 간격(20–60s)에서는 작동한다.
- **적중 조건 = 공유 프리픽스가 모델별 최소치 이상**: 2.5-flash **2,048토큰** / 3.5-flash **4,096토큰** (공식 문서 + 명시적 캐시 API 400 실측 일치). `systemInstruction`도 프리픽스에 **포함**됨(실측: 시스템 위주 7.0k 요청에서 6110 캐시).
- **현 게임 경로 실측(20s 간격, 재배열 v1)**: 2.5·3.5 모두 적중 0 — 턴 간 안정 프리픽스가 ~1.5–1.8k토큰(시스템 1012 + 유저부 수백)으로 양쪽 임계 미달.
- **원인 분해**: ① 동적 anti-repeat 노트가 노트 목록 앞쪽(인덱스 1–4)에 끼어 프리픽스를 깨고, ② memories/shards 슬라이딩 윈도우가 payload에서 노트보다 앞에 있으며, ③ `MAX_PROMPT_NOTES=8`이 노트 21개 중 마지막 8개만 렌더 → **언어/시네마틱/네이밍/인과율 규칙이 일반 턴에 모델에 도달하지 않는 별도 문제 발견**(프리픽스와 무관하게 검토 필요).
- **v2 구현+실측 완료 (`1014e52`)**: 노트 조립 안정 우선 재배열 + payload 슬라이딩 윈도우 후진 + `MAX_PROMPT_NOTES` 8→48(규칙 노트 잘림 수정). 실측 — 턴 간 안정 프리픽스 **1.5k → 2.55–2.85k토큰**(턴 2+), 2.5-flash 임계 통과; 실제 게임 경로에서 **첫 캐시 적중 기록**(2.5, 20s 간격, `cached=3839`). 적중은 best-effort라 간헐적(전파 지연) — 긴 루프에서 워밍업 후 적중률 상승 기대, 라이브 플레이에서 재확인. 부작용: 규칙 노트 복원으로 턴 입력 +~1.4k토큰(2.5 기준 +$0.0004/턴, 적중 시 상쇄) — 이건 비용이 아니라 **의도된 지침이 도달 안 되던 버그의 수정**. 3.5의 4096은 여전히 ~1.2k토큰 부족 — KO 디렉티브 팩 전체를 시스템으로 옮기는 재설계(품질 QA 필요)가 남은 갭. 주의: gemini-3 계열 **9k–17k 프롬프트 캐시 데드존** 보고([python-genai#2064]) — 3.5 적용 시 실측 필수.
- 3.5 이행 시 별도 마이그레이션: `thinking_budget` → `thinking_level`(둘 다 보내면 400; 현재는 budget=0 단독이라 안전).
- 3.5 절감 대안(캐싱 외): 키비트 턴만 3.5·일반 턴 2.5의 **모델 이원화**(`generate(model=...)` 시임 존재).
- CBT 기본값은 2.5 유지. 3.5 전환은 라이브 플레이 평가(`MODEL=gemini-3.5-flash make api`) 후 프로즈 가치로 판단.

## 최종 판정 (2026-07-04 밤, 12턴 실측 + AGY 브라우저 QA)

- **캐시 적중률 실측(3.5, 13콜, 20s 간격, 안정 프리픽스 ≥4096 달성 상태)**: **1/12 (~8%)** — call 8에서 4047토큰 캐시. 프리픽스는 임계를 넘었으나(4047 캐시가 증명) 11~12k 프롬프트 구간에서 암시적 적중이 극히 드묾(#2064의 9–17k 열화 구간과 일치). **결론: 캐싱은 현재 3.5 비용을 실질적으로 못 깎는다** (실측 −1.7%, 이상적 100% 적중 가정에도 −22%).
- **비용 실측 (프롬프트 avg 11.5k / 출력 0.84k)**: 3.5 = $0.025/턴 ≈ **$1.24/50턴 루프**; 2.5 동일 프롬프트 = $0.005/턴 ≈ **$0.26/루프** → **4.8배**, 캐싱 포함해도 유지.
- **AGY 브라우저 QA (3.5+Imagen 로컬 스택, run `gemini35-eval-210231`)**: **PASS_CANDIDATE** — 3체크포인트 플레이, 콘솔/네트워크 클린, 스탯보이스·선택지·이미지 전부 정상. 파이프라인 리스크 없음.
- **권고**: ① CBT 규모(8명×10루프=80루프)에선 3.5 전면 전환 시 서사비 ~$99 vs 2.5 ~$21 — 절대액이 작아 **품질 우선이면 전환 가능**. **→ 채택: 2026-07-04 밤 Cloud Run `MODEL=gemini-3.5-flash` 전환 (rev `mythos-api-00018-pj9`, 실서사 1턴 라이브 확인). 롤백은 env 한 줄.** ② 비용 민감 시 **키비트 이원화**(≈$0.5/루프). ③ 캐싱 실효를 원하면 **프롬프트 다이어트로 <8k 진입**(적중 신뢰 구간 + 직접 절감 동시 확보)이 선행 과제 — 현 11.5k는 규칙 복원+캐논 확장의 대가.

## 후속 구현 실측 — 프롬프트 다이어트 + 키비트 이원화 (2026-07-04 심야)

권고 ②·③을 모두 구현하고 라이브 재실측했다 (커밋: diet + `GEMINI_MODEL_KEYBEAT`).

- **프롬프트 다이어트 (11.5k → 8.5-8.6k, −25%)**: 토큰 분해 하네스(`scratch/prompt_breakdown.py`, Vertex `count_tokens`)로 원인 특정 — 프롬프트의 ~2.7k토큰이 **기계 레코드**였다: `memories[-4:]`가 매 턴 갱신되는 autosave `save_slot`으로 가득 차고(→ **echo 계승 기억이 윈도우에서 밀려나 GM에 도달 못 하던 크라우드아웃 버그 동시 수정**), `world_memories`는 `narrative_metrics` 텔레메트리, loop/이벤트에 UUID·seed·타임스탬프. 서사 kind 화이트리스트(echo/archive_rollup/loop_archive; run_summary·causality_summary는 노트 채널이 이미 다이제스트 → 중복 배제) + 필드 슬리밍으로 해결. 오프라인 정상 구간 7.5k; 라이브(3.5, 11콜) avg **8,593** — 실제 프로즈가 캔드보다 길어 8k를 소폭 상회하나 **9-17k 열화존 탈출**. 잔여 컷 후보는 전부 프롬프트-필 민감(직전 장면 원문 420자×2 윈도우, STAT VOICE REFERENCE 565tok — 후자는 3.5 캐시 프리픽스 ≥4096 유지에 필요)이라 중단.
- **다이어트 후 캐시 관찰**: 라이브 3.5 프로브에서 call 9 `cached=4029`(프리픽스 히트), 키비트 프로브 call 0 `cached=8051`(**이전 프로브 런과의 크로스-리퀘스트 풀 히트** — 8.2k 프롬프트가 통째로 적중). 표본이 작아 적중률 재판정은 보류; 직접 절감(−25% input)은 무조건 확보. 3.5 전면 시 $1.24 → **~$1.0/루프**.
- **키비트 이원화 구현+라이브 검증**: `NarrativeContext.key_beat`(오프닝 프롤로그/앵커 비트락/컴패니언 컷신/보스 빌드업/REWRITE·ARCHIVE 엔딩) → `GEMINI_MODEL_KEYBEAT` 모델로 생성, 일반 턴은 `MODEL`. 미설정 = 단일 모델(현행 그대로). 라이브 프로브(9콜): 턴 0-4 → 3.5-flash, 턴 5-8 → 2.5-flash 정확 분기; **2.5-flash가 global 엔드포인트에서 정상 서빙**(3.x 혼용 시 클라이언트가 global로 해상, 404 없음). 예상 비용 **~$0.5/루프**.
- **운영 선택지 (env만으로)**: ① 현행 = 전면 3.5 ($1.0/루프, 다이어트 반영) ② `MODEL=gemini-2.5-flash` + `GEMINI_MODEL_KEYBEAT=gemini-3.5-flash` = 키비트 하이브리드 (~$0.5/루프) ③ `MODEL=gemini-2.5-flash` 단독 = 전면 2.5 ($0.2/루프). 하이브리드의 프로즈 체감은 `[manual]` 라이브 사인오프 대상.
