기준 문서: [플레이스토어 출시 실행 계획](plans/2026-11-05-play-store-release-plan.md). 기존 무료 다운로드 + 선택 구독안을 유지하며 **무료 앱 테스트·출시 먼저, Signal+ 판매는 후속**을 권고한다. 계획 정리 요청을 실제 결제·게시 승인으로 보지 않는다.

재개할 때 필요한 정보는 다섯 가지다.

- [ ] Play Console 계정 유무·개인/조직·생성일·검증 상태. 해당 신규 개인 계정은 12명 연속 14일 비공개 테스트 후 생산 접근을 신청한다.
- [ ] 무료 우선안 채택 여부, 초기 국가, 공개 개발자 명의와 지원 이메일. 정책 URL은 운영 중이나 연락처가 없어 제출 전 보완해야 한다.
- [ ] 업로드 키와 안전한 백업·서명 설정. 비밀번호/키를 채팅이나 저장소에 넣지 않는다.
- [ ] 비공개 테스터 확보·연락 담당. 내부/Firebase 배포와 Play 비공개 테스트 요건을 구분한다.
- [ ] Android 실기기와 재미 판정 담당. 현재 웹 검증은 Android 서명/기기/결제 검증을 대체하지 않는다.

크기 검사·구매 UI·16KB 실행·구형 WebView 안내는 로컬 검증을 마쳤다. FCM 정리·debug 업데이트·키보드 검증과 정책 초안 보완도 완료했다. 실기기/Play 서명·정책 공개·운영 정리 작업의 검증은 남아 있다. 계정 등록·결제, 필요한 IAM 변경, 업로드와 최종 공개는 계획의 담당/완료 기준에 따라 진행한다.

- [ ] Neon 콘솔에서 실제 History window, 스냅샷·외부 백업 유무를 확인. 연결 주소/키 대신 보관 기간·복구 범위만 공유한다. [D7 확인 절차](plans/2026-11-05-data-locations-backup-audit.md). 복원이나 보관 설정 변경은 아직 수행하지 않았다.
