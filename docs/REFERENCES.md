# Design References

Mythos 2.0이 참고하는 게임과 가져온 지점. 구현 현황은 `STATUS.md` / `NEXT_PLAN.md`를 본다(이 문서는 변하지 않는 레퍼런스만).

| 게임 | 가져온 것 |
|---|---|
| **Into the Breach** | 적이 다음 행동을 미리 보여 주는 예고, 밀치기·충돌·환경 처치가 정답인 퍼즐형 전투, 작은 보드 |
| **Slay the Spire** | 3막 지도(갈림길·정예·휴식·상점), 카드 보상 1/3, 렐릭에 해당하는 임플란트, 보스 전 휴식처, 패러독스(어센션) |
| **Hades** | 죽어도 의미가 남는 메타 루프(아카이브 해금), 동료 관계가 판을 거듭하며 깊어지는 구조, 짧은 런 |
| **Citizen Sleeper / Disco Elysium** | 판정의 결과를 숫자가 아니라 세계의 반응으로 쓰는 사건 문체 |
| **Wildermyth** | 한 판의 기록이 연대기가 되는 마무리(루프 기록) |

원칙: 숫자와 확률은 먼저 보여 주고(선택의 무게), 글은 그 결과를 장면으로 남긴다.
