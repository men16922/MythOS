# Docs Archive

이 디렉터리는 current docs에서 제외된 과거 문서를 보존한다.

정책:

- archive 문서는 직접 업데이트하지 않는다.
- 현재 상태는 `../STATUS.md`, 다음 계획은 `../NEXT_PLAN.md`, 완료 요약은 `../COMPLETED_SUMMARY.md`를 기준으로 한다.
- archive 문서를 삭제하려면 먼저 핵심 내용을 current docs에 요약하고, `rg`로 참조가 없는지 확인한다.

## Files

- `IMPLEMENTATION_M0_M10.md`: M0-M10 상세 구현 추적, work log, verification log archive.
- `progress-2026-05.md`: 2026-05 증분 작업 상세 로그 archive.
- `DRAFT.md`, `DESIGN_SYSTEM_STATS.md`, `ARCH_MAP.md`: 현재 문서로 요약된 retired 기획/설계 문서.
