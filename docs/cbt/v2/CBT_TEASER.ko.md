## 1. 티저의 한 문장

> **네오서울은 당신의 선택을 기억한다. 다음 이야기를 고르고, 동료를 지키고, 직접 싸워라.**

Project MythOS의 본질은 네 축이 한 번의 플레이 안에서 연결되는 데 있다.

| 축 | 티저에서 보여 줄 경험 | 관객이 받아야 할 인상 |
| --- | --- | --- |
| **세계관** | 비 내리는 각성, 야시장, 지하, 소각로, 첨탑, IX | “들어가 보고 싶은 SF 세계다.” |
| **AI 게임마스터** | 선택 → 즉시 이어지는 서사와 장면 → 다음 갈림길 | “정해진 컷신이 아니라 내 선택을 받아 준다.” |
| **관계와 루프** | 세린/동료의 만남, 경로 변화, 에코와 다음 루프 | “이야기가 한 판으로 소모되지 않는다.” |
| **전술 전투** | 예고를 읽고, 엄폐·상태·수류탄·밀치기로 뒤집는 한 턴 | “이건 내가 판단해서 이기는 전투다.” |

전투는 가장 강한 게임플레이 증거이지만 **약 30초**만 쓴다. 나머지는 그 전투가 왜 벌어지고,
무엇을 잃고 얻는지를 보여 주는 데 쓴다.

**피할 것**: AI 생성 과정/로딩을 길게 보여 주기, 기능 목록을 읽는 자막, 빈 전투 보드, fallback 정적 전투,
존재하지 않는 기능을 연출로 보충하기.

### 반드시 확보할 실플레이 원본

1. 선택지 → 서사 스트리밍 → 해당 장면 이미지가 이어지는 한 번의 연속 샷.
2. 작전 지도에서 갈림길 선택 뒤 새 노드가 열리는 샷.
3. 동료 만남 또는 컷신 → CHARACTER 탭 → 다음 전투에서 직접 조작하는 연결 샷.
4. 비폴백 전투에서 적 의도·조준 프리뷰·엄폐 또는 지원·밀치기 충돌이 한 번에 이어지는 샷.
5. 수류탄/상태이상/스킬 컷인과 4인 승리 라인업.
6. Run History 또는 에코가 다음 루프에 남는 샷.

### 촬영 / 편집 규칙

- 전투는 반드시 `?fallback=0` 상태로 촬영한다. fallback 정적 전투는 쓰지 않는다.
- 이미지 리소스는 정지 슬라이드쇼처럼 길게 두지 말고, **실제 UI·선택·전투 결과 사이를 연결하는 컷**으로 쓴다.
- AI 생성/로딩 화면은 최대 1–2초. 결과 장면과 다음 선택을 길게 보여 준다.
- 자막은 화면당 한 문장, 7단어 안팎. 세계관 자막과 전투 자막의 밀도를 같게 유지한다.
- 음악은 0:00–0:53에 세계관/관계의 상승감을 만들고, 0:53–1:27에만 전투 드롭을 준 뒤, 1:38부터 결말/CTA로 다시 넓힌다.
- 실제 플레이와 다른 피해 수치·기능·결말을 합성하지 않는다.
