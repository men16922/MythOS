# GCP 클로즈베타 피드백 전략 (CLOSED_BETA_FEEDBACK_STRATEGY.md)

작성일: 2026-06-27 · 상태: 활성 계획(active) · 성격: 영어버전 완성 후 **실제 테스터로 핵심 루프를 검증**하는 전략
(구 `LOCAL_VERSION_FEEDBACK_STRATEGY.md` 대체).

배포 기술안은 `docs/cloud/GCP_PLAN.md`, 커리어 레버리지는 `docs/cloud/CAREER_STRATEGY.md`. 이 문서는 *무엇을·
누구에게·어떻게 검증/공유*하는가를 다룬다.

## 0. 목표 / 핵심 결정 (확정)

- **검증 대상 = 재미·핵심 루프** — "AI GM 서사 + 선택 결과 + 결정론 전투 + 루프 carry-over"가 실제로 재밌고
  30~60분 따라가지는가. **영상만으로는 검증 불가** → 낯선 사람이 *직접 플레이*해야 한다.
- **제품 LLM = Gemini (Vertex)** — 클라우드 배포·베타는 **Gemini provider**(controlled generation, 3b 파서 제거)로
  서비스. **로컬 LLM(Ollama)은 dev/QA 환경일 뿐 제품 정체성 아님.** `fully local LLM game` 프레이밍 폐기.
- **영어 우선** — EN/KO 풀 바이링궐, 영어 default(`docs/plans/2026-06-27-en-ko-localization.md`).
- **검증은 클로즈베타로** — 영상은 r/playtesters 모집글의 *티저*로만 보조적으로 사용(검증 산출물 아님).

## 1. 왜 클로즈베타인가 (영상의 한계)

영상은 "신기하다"까지만 전달한다. MythOS의 가치는 **인터랙티브 루프**(선택→결과→전투→여파→다음 루프 기억)라,
플레이어가 직접 의사결정을 하고 결과를 겪어야 재미·페이스·이해도·재플레이 동기를 판단할 수 있다. 따라서:
- 5~10명이 **각자 1~2 루프를 끝까지** 플레이 → 구조화된 피드백.
- 측정: 30~60분 완주율, 기억나는 장면 수, 중도 이탈 지점, "다시 하고 싶다" 여부.

## 2. 최종 시퀀스 (확정)

1. **영어버전 + 로컬 QA** — EN/KO 영어 default 완성(plan S0~S4) + neo-seoul live-QA A·F 사인오프(로컬 LLM으로).
2. **Gemini provider 로컬 검증** — `VertexGeminiJSONProvider`(controlled generation→3b 파서 제거)를 Ollama 공존
   provider로 추가, **클라우드 올리기 전에 로컬 서비스계정으로 실측**(서사 품질·스키마 유효·지연·비용). `CAREER_STRATEGY.md` §5-1.
3. **GCP 제한형 클로즈베타 배포** — 최소기능(§3) Cloud Run(WS) + GCS + Imagen + Gemini. 초대키 게이팅 + 비용/용량 캡.
4. **r/playtesters 모집 (5~10명)** — §4.
5. **핵심 루프 개선** — §5 피드백 루프로 재미/페이스/이해도 개선(neo-seoul live-QA·findings로 회수).
6. **r/aigamedev 결과·아키텍처 공유** — §6. 모집 아님, **클로즈베타 결과 + AI 게임 설계 토론**.
7. **공개 베타** — 안정화 후 공개 링크 확대.

## 3. 최소기능 클로즈베타 스코프 (배포 게이트)

낯선 사람이 영어로 **1 루프를 끝까지** 도달하는 데 필요한 최소집합만:
- **플레이 가능 경로**: 온보딩 → golden-path(오프닝~첫 전투~종료) 영어로 완결. (전체 백필 불요 — 골든패스 우선.)
- **Gemini provider**: 서사 생성 + controlled generation 스키마 유효. 실패 시 graceful(파서 제거로 단순화).
- **접근 게이팅**: 초대키/링크 한정. 신규 가입 폭주·비용 폭발 방지.
- **비용·용량 캡**: 테스터당 루프 수 제한 + Gemini/Imagen 일일 쿼터 + Cloud Run min-instance 0(유휴 비용 0).
- **피드백 캡처**: (a) 종료 화면 → 짧은 설문 링크(§5 질문), (b) 전용 Discord 채널, (c) 기존 run-history/narrative
  metrics 영속(이탈 지점·완주율 자동 수집).
- **관측성**: Cloud Trace(OTel exporter 교체)로 지연·실패 추적.

> 비고: 풀 EN/KO 백필·전체 시나리오 2종은 **공개 베타 전**까지로 미룬다. 클로즈베타는 골든패스 영어 한 경로면 충분.

## 4. 테스터 모집 (5~10명) — 채널 재조정 (2026-07-01)

- **1순위 = r/Solo_Roleplaying** — MythOS는 본질이 "AI 내레이터 + 결정론 전투"라, 솔로 TTRPG(오라클·GM 에뮬레이터·
  저널링) 커뮤니티가 **장르 최적합 + 고신호 피드백**. **단 모집 전용 서브가 아님**(취미/토론) → 톤은 "만든 거 공유,
  봐줄래?"이고 **상호 호혜 프레이밍 금지**. **AI 감정선이 1순위 리스크**(공개 필수, "AI가 GM 대체" 표현 금지, 결정론
  전투를 셀링포인트로 앞세움). 자기홍보·AI 규칙 **게시 직전 확인 + 필요시 모드 선연락**. 맞춤 글: `CBT_RECRUIT_SOLORP.md`.
- **2순위 = r/interactivefiction** — 서사 피드백 질 높지만 **AI에 더 보수적**(공개 의무, 일부 이벤트는 생성형 AI 금지).
  공개·도구(대체 아님) 프레이밍 + 규칙 확인 후에만.
- **보조 = r/playtesters** (+r/playtest, r/DestroyMyGame) — 빠른 수 확보용 funnel. **상호 플레이 호혜 규범** 존중. 글:
  `CBT_RECRUIT_POST.md`. (장르 적합도는 낮아 깊이보다 양.)
- **티저 = YouTube 링크**(네이티브 임베드 아님). 검증 산출물 아니라 보조재(§7).
- 기존 채널 단일(r/playtesters)에서 **장르 적합 우선**으로 전환한 근거: r/playtesters의 호혜 규범은 의무적·얕은 피드백을
  낳아 "핵심 루프가 재밌나"라는 검증 질문엔 약함.
- **모집글 구성**: (a) 한 줄 정체성(*"AI가 진행하는 SF 내러티브 RPG, 전투는 결정론 엔진"* — `fully local` 표현 금지),
  (b) **무엇을 봐주길 원하는지**(핵심 루프 재미·30~60분 완주·이해도), (c) 소요시간/접근법(초대키), (d) **티저 영상/GIF**
  (선택, 짧게), (e) 피드백 방법(설문+Discord).
- **스크리닝**: SF/RPG/AI 게임에 관심 있는 5~10명. 다양성(장르 친숙도 상/하 섞기)으로 온보딩 난이도 검출.
- **기대치 합의**: 미완성 베타임을 명시, 버그보다 *재미·핵심 루프* 피드백 우선이라고 안내.

## 5. 피드백 수집 · 반영 루프

- **구조화 질문**(핵심 루프 정조준): ① 30~60분 길을 잃지 않았나 ② 기억나는 장면 3개 ③ 선택이 이야기로 체감됐나
  ④ 전투가 추격/결과로 느껴졌나 ⑤ 종료가 납득됐나 ⑥ 다시 하고 싶은가 ⑦ 가장 혼란/지루한 지점.
  (neo-seoul live-QA C/D/E/G/H/I와 정렬.)
- **자동 신호**: 완주율·이탈 노드·턴당 지연·전투 결과 분포(run-history/metrics).
- **회수**: 발견을 `docs/test/neo_seoul_live_qa.md` 또는 신규 findings로 → 우선순위화 → 핵심 루프 개선 → 재배포.
- **반복**: 라운드별 5~10명, 2~3 라운드까지 개선이 수렴할 때까지.

## 6. r/aigamedev 후속 (모집 아님 — 결과·아키텍처 공유·토론)

클로즈베타로 *검증/개선*이 어느 정도 된 뒤, AI 게임 제작 커뮤니티에 **결과 + 설계**를 공유:
- **무엇을 풀었나**: LLM GM ↔ **결정론 전투 분리**, **Gemini controlled generation으로 구조화 출력**(파서 모델 제거),
  세션 메모리(RAG 아님) 반복 억제, 앵커 DAG로 "의도된 즉흥", 캐릭터/장면 시각 일관성.
- **무엇을 배웠나**: 클로즈베타 테스터 피드백에서 나온 핵심 루프 인사이트.
- **형식**: 결과 요약 + 아키텍처 글(블로그/포스트) + 토론 유도. **모집이 아니라 회고·토론** 채널.

## 7. 프레이밍 (정정)

- **제품 정체성** = "AI가 진행하는 SF 내러티브 RPG (서사=Gemini/Vertex, 전투=결정론 엔진)". 클라우드 네이티브.
- **로컬 LLM(Ollama)** = 개발·QA 환경 디테일. **헤드라인/정체성에서 제외.** `fully local LLM game` 표현 사용 금지.
- 영상/GIF = 모집 티저 보조재. 검증의 주체는 **테스터의 실플레이**.
