# Neo-Seoul Live QA Checklist

최종 갱신: 2026-06-09

이 문서는 `neo-seoul`을 사람이 직접 플레이하면서만 판단할 수 있는 항목만 다룬다. 자동 테스트, JSON 검증,
빌드/린트, API 동작 확인은 포함하지 않는다. §0′은 최근 플레이에서 나온 발견/후속 작업, §0은 이번 사이클에
**우선 확인할 항목**이고, §1~8은 상시 유지하는 전체 체크리스트다.

## 0′. 플레이 발견 — 후속 작업 (2026-06-09)

시뮬레이터/라이브 플레이에서 나온 UX 이슈와 처리 상태. 완료 항목은 다음 live QA에서 체감만 재확인한다.

- `[x]` **작전 지도 레이아웃**: 기본 지도는 compact 그래프로 줄이고, 확대 모달은 넓은 스크롤 레이아웃 +
  grid 범례로 재배치해 범례/텍스트 겹침을 제거. (시각 체감은 다음 live QA에서 재확인)
- `[x]` **인벤토리 RPG화**: 기억의 별자리 인벤토리를 무기/방어구/소모품/재료/키/데이터 분류 + lucide
  아이콘 기반으로 재구성.
- `[x]` **기억의 별자리 장비 착용 버튼 미표시**: `item_id` table-form 인벤토리도 equipment 정의로 해석하도록
  serializer/runtime/combat item id 경로를 보강하고, 장비 행에 착용/해제 버튼을 안정적으로 표시.
- `[x]` **전투 소모품 버튼 노출 조건**: 소모품 보유 0개일 때도 전투 컨트롤에 "소모품" 섹션과 빈 상태를 표시.

위 항목은 코드 반영 완료. 다음 사람 플레이에서 시각/체감만 재확인한다.

## 0. 이번 사이클 우선 확인 항목 (2026-06-08)

자동(in-process LLM) QA로 기술 파이프라인은 검증했으나(파싱 예외 0·멈춤 없음·전투 후 재개·패배 종료 정상),
아래는 **사람 플레이로만** 판단 가능한 현재 최우선 확인 항목이다. 실행: `make dev-up` 후 `http://localhost:8000`
(Ollama `ollama serve` 필요, 이미지 끄려면 온보딩에서 fallback/image off).

- `[!]` **F1 반복 완화 체감(수정 적용됨)**: 같은 장소에 머무는 동안 장면 도입부가 매번 "오존 냄새/배경 묘사"로
  다시 시작하지 않고, 새 사건·대사·행동으로 진입하는가. (자동 14턴 재검증서 반복 0 확인 — 사람 체감 확인 필요) -> 오존 냄새가 반복적으로 보여짐
- `[~]` **F2 전투 빈도 체감(코드 수정 적용·재확인 필요)**: 초반 10장면 안에 전투가 너무 자주/연속으로 끼어들어 서사를
  끊지 않는가. 전투가 추격·작전 실패의 결과로 납득되는가. (자동 런 변동성 큼 — 튜닝 여부는 사람 판단) - 전투가 4턴만에 2회 일어나서 너무 잦음
  → `_gate_next_combat` 쿨다운(3장면, 고압 예외)으로 연속 전투 억제. 다음 플레이에서 체감 재확인.
- `[ ]` **전투 후 내러티브 재개 자연스러움**: "계속 ▸" 후 다음 장면이 전투 여파를 반영하며 매끄럽게 잇는가.
- `[x]` **Tactical Board 신규 UX**: 범례·타일 인스펙터(hover)·전투 시작 학습 목표 배너가 의미 전달에 도움되는가.
- `[~]` **조우 난이도 곡선(난이도 캡 적용·레벨업 체감 미해결)**: 튜토리얼(patrol)은 쉽고, 후반(enforcer/wraith)은 target priority/이동/타이밍을 요구하는가. - 초반 4턴만에 enforcer 만나서 게임오버, 그리고 전투 이후 레벨업 - 강해지는 느낌이 없음
  → `_gate_next_combat` 초반 난이도 캡(승리 횟수별 risk 1→2→3→4, 초과 시 다운그레이드)으로 조기 enforcer 즉사 방지. **레벨업 강화 체감은 미해결**(별도 작업 A 잔여).
- `[ ]` **phase 정체 점검**: 장기 진행 시 막/단계 전환이 느껴지는가, 아니면 계속 같은 톤(explore)에 머무는가.

문제 발견 시 `[!]` + 한 줄 메모를 남기고 `docs/PROGRESS_LOG.md`/`docs/NEXT_PLAN.md`에 반영한다.

## 플레이 조건

- 시나리오: `neo-seoul`
- 권장 길이: 30-60분
- 권장 경로: Golden Path 1회, 실패/우회 Path 최소 1회
- 기록 방식: 각 항목을 `[ ]` 미확인, `[x]` 통과, `[!]` 문제 있음으로 표시하고, 문제는 한 줄 메모를 남긴다.

## 1. 첫 5분 Hook

- `[x]` 부팅/오프닝에서 사용자가 `접속 기동` 또는 시나리오 시작 버튼을 누른 뒤 BGM이 켜진다.
- `[x]` 시나리오 오프닝을 수락한 뒤에도 BGM이 유지되거나 자동 재시도된다.
- `[!]` 플레이어가 자신이 "비식별 신호"이고 관리자 IX에게 지워질 위험이 있다는 점을 이해한다. - 위험한 건 알겠는데, 왜 위험한지 모르겠음
- `[x]` 세린을 따라갈 이유가 정보 전달이 아니라 상황, 대사, 위험으로 납득된다.
- `[!]` 첫 선택이 단순 진행 버튼이 아니라 시민/데이터/안전 중 무엇을 택하는지 느껴진다. + 무슨 의미인지 잘 모르겠어
- `[x]` 첫 장면 이후 다음 목표가 명확하다. -> 뭘 해야할지 모르겠고, 상황만 흘러감. 최소 생존이나 탈출 같은 목표는 있어야 할 것 같음

## 2. 선택의 맛

- `[!]` 매 장면 선택지가 서로 다른 가치 판단처럼 보인다: 사람, 증거, 안전, 통제. -> 선택지가 직관적이지 않고, Peception 체크 등도 무슨 의미인지 모르겠음.
- `[!]` 선택 후 NPC 태도, 안정도, 추적도, 단서, Codex/Shard 중 하나 이상의 변화가 체감된다. -> 세린으로부터 거리를 두고, 어둠 속으로 숨어 독자 탈출을 꾀한다. 를 택해도 스토리가 달라지는게 없음
- `[!]` 선택 결과가 너무 늦게 오거나 너무 추상적으로 느껴지지 않는다. -> 선택지 이후 텍스트 스트리밍이 느림. 더 빨라야 함
- `[!]` 실패/우회 선택도 손해만 주지 않고 다른 정보나 톤을 준다. -> 선택에 따라 뭐가 다른지 모르겠음

## 3. 캐릭터 존재감

- `[!]` 세린은 단순 안내자가 아니라 자기 판단과 감정으로 플레이어를 밀거나 붙잡는다. -> 캐릭터성은 있어 보이나, 비슷한 말만 반복하고 목적이 보이지 않음
- `[ ]` 린위에는 거래의 이득과 부채를 동시에 느끼게 한다.
- `[ ]` 카이 RX-09는 보상 장비가 아니라 "기계도 기억할 수 있는가"라는 테마를 연다.
- `[ ]` 관리자 IX는 추상 시스템이 아니라 플레이어 선택을 정정하려는 압력으로 느껴진다.

## 4. 전투 만족감

- `[X]` Codex/개발 로그 탭에 갔다가 Story로 돌아와도 Tactical Board가 즉시 보인다.
- `[~]` Tactical Board의 아이콘, 지형, 위험 칸, 적 의도가 무엇을 뜻하는지 플레이 중 이해된다. -> 범례나 아이콘은 괜찮으나, 지형 아이콘의 이미지가 직관적이지 않고, 택티컬 보드가 너무 작음. 비율을 늘려야 할 것으로 보임. + - 버튼이 비정상적으로 작동함. 우측 PARTY,ENEMY, 표적, 행동, 스킬 솜품 등의 창을 아래로 내리는건 어떨까?
  → 줌 +/- 버튼 비정상 작동 수정(0.25 격자 스냅). 보드 기본 비율 확대(1.8fr→2.6fr),
  위험 칸 글리프(☣/⚡) 추가로 범례 일치. **미해결**: 우측 패널 하단 재배치(E 잔여, 큰 리플로우라 방향 확정 후).
- `[x]` 전투 승리 후 통찰/안정도/추적도/전리품 변화가 전투 결과 패널에서 이해된다.
- `[!]` 전투가 갑자기 끼어든 미니게임이 아니라 추적, 작전 실패, 구출, 동료 보호, 보상 중 하나의 결과로 느껴진다. -> 텍스트로 일부 표시되기는 하나, 장면과의 연결성은 느껴지지 않음
- `[x]` 첫 전투는 조작과 기본 전술을 배우기에 충분히 쉽다.
- `[ ]` 중반 이후 전투는 target priority, 방어 timing, 이동/거리, 스킬 선택 중 하나를 요구한다.
- `[!]` 승리 후 무엇을 얻었는지 보인다: 통찰, 단서, 아이템, 관계 변화, 다음 루프 정보. -> 전투 승리 이후 통찰, 아이템만 알 수 있음. 다른 건 모르겠는데, 뭘 보여줘야하지?
- `[!]` 패배/도주/손실도 이야기 흐름을 끊지 않고 후속 결과로 이어진다. -> 패배하면 루프 끝남.

## 5. 페이스

- `[!]` 작전 지도에서 현재 위치, 다음 이동지, 접근 중인 접촉, 이동 위험이 이해된다. -> 위치를 이동은 하는거같은데, 선택지에 따라 어느 루트로 이동하는지 잘 모르겠음.
- `[!]` 초반 10장면 안에 전투가 강제로 반복되어 서사 진행을 막지 않는다. -> 전투 자주 일어나고, 스토리 의미가 없게 느껴짐
- `[!]` 10-15분마다 플레이 감각이 바뀐다: 추격, 은신처, 조사, 거래, 작전, 전투, 동료화, 최종 대면. -> 무의미한 텍스트의 나열, 장면 전환이 의미가 없고, 전투도 급작스레 일어나고 끝남
- `[!]` 같은 톤의 텍스트가 길게 이어져 피로해지지 않는다. -> 비슷하고 무의미한 텍스트로 느껴짐. 매 장면 및 선택마다 이동이 되어야 함
- `[!]` 전투와 서사 템포가 서로 방해하지 않는다. -> 매끄럽게 이어지는 느낌이 없음
- `[x]` Codex, Run History, 진행도 화면으로 이동할 이유가 자연스럽다.
