# Quarkify PoC 결과 (2026-06-18)

> 코드를 폴더 구조로 분해해 AI가 grep 없이 탐색하게 하는 도구. 패키지 2개(소/대)로 검증함.

## TL;DR
- **검색 비용(토큰) 절감 확인** — 정확도는 기존과 동일.
- 절감폭은 코드 규모에 정비례: 작은 모듈 50~70%, 큰 모듈 **80~92%**.
- 결론: **큰 코드베이스에서 유의미.** 자동 재생성 갖추면 도입 권고.

## 무엇을 했나
- 1차: `mythos_loop` (539줄) — 질문 3개, grep vs Quarkify 비교 → 정답률 3/3 동일
- 2차: `mythos_runtime` (10,072줄, session.py 2,088줄 포함) — 검색어별 토큰 측정

## 핵심 결과 (검색 1회 컨텍스트 토큰)
- 작은 모듈(539줄): 흔한 검색어 절감 50~70%
- 큰 모듈(10,072줄): `store` 235히트 → 92%↓, `loop` 777히트 → 82%↓ (한 검색에서만 ~2만 토큰 절약)
- 정확도: 양쪽 동일 / 헛검색 반복: 4~7회 → 0회
- 생성 속도: 10k줄을 2초

## 규모별 효과 (한눈에)
- 검색어 히트 ≤15 → 절감 거의 없음/손해 (grep이 이미 최소)
- 히트 ~30~90 → 55~79% 절감
- 히트 200+ → 80~92% 절감
- → **임계 ≈ 모듈 1,500줄 / 검색어 히트 30 부근**부터 유의미

## 한계 / 주의
- 작은 파일(≲500줄)·드문 검색어는 기존 grep으로 충분.
- 코드 바뀌면 재생성 필요(가볍고 빠름, 2초).
