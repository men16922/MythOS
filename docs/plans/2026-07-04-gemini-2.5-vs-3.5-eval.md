측정 도구: `scratch/gemini_model_bench.py`(A/B 세션 벤치) + `scratch/gemini_token_probe.py`(토큰 실측).

## 품질이 올라가는 방식 (샘플)

**턴 0 — '첫 접속' 동일 비트:**
- 2.5: "차가운 빗물이 얼굴을 때리고, 낡은 콘크리트 바닥의 축축한 감각이 피부에 와닿는다. … 물웅덩이에 번진 네온사인 빛이 일그러진 무지개처럼 흔들린다."
- 3.5: "눈꺼풀을 짓누르는 어둠이 2.7초간의 침묵 끝에 걷힌다. 뺨에 닿는 것은 얼어붙을 듯 차가운 젖은 콘크리트 바닥, 그리고 **코끝을 찌르는 시큼한 오존과 탄 타이어 냄새**다."

**턴 2 — '내밀어진 손' 동일 비트:**
- 2.5: "바이크의 엔진 소리가 빗소리에 섞여 낮게 울리고, 멀리서 감시 드론의 탐조등이 골목을 느리게 훑으며…"
- 3.5: "웅크린 그녀의 가죽 재킷에서 **젖은 가죽 냄새와 뜨거운 엔진 오일 향**이 번진다. 당신의 마비된 몸 위로 그녀가 가늘고 굳은살 박힌 손을 조용히 내민다."

요약: 3.5의 향상은 ① 감각 채널 확장(시각→후각/촉각/체온), ② 구체 수치·물성 디테일, ③ 문장 연결의 영화적 리듬, ④ 스탯/기제 신호의 서사 내 자연 통합. 파싱·지연·안정성은 동급이므로 **순수하게 프로즈 밀도 대 비용(4.7×)의 트레이드오프**다.

## 컨텍스트 캐싱 — 진단 정정 (2026-07-04 저녁, 웹검색+재실측)

- **"암시적 캐싱 미작동"은 오진**이었다: 캐시 쓰기 **전파에 수초~수십초**가 걸린다. 2초 간격 3연속은 0이지만 **20초 간격이면 2.5·3.5 모두 적중**(동일 7.6k 프롬프트: 2.5=7146, 3.5=6117 캐시). 실제 플레이 턴 간격(20–60s)에서는 작동한다.
- **적중 조건 = 공유 프리픽스가 모델별 최소치 이상**: 2.5-flash **2,048토큰** / 3.5-flash **4,096토큰** (공식 문서 + 명시적 캐시 API 400 실측 일치). `systemInstruction`도 프리픽스에 **포함**됨(실측: 시스템 위주 7.0k 요청에서 6110 캐시).
- **현 게임 경로 실측(20s 간격, 재배열 v1)**: 2.5·3.5 모두 적중 0 — 턴 간 안정 프리픽스가 ~1.5–1.8k토큰(시스템 1012 + 유저부 수백)으로 양쪽 임계 미달.
- **원인 분해**: ① 동적 anti-repeat 노트가 노트 목록 앞쪽(인덱스 1–4)에 끼어 프리픽스를 깨고, ② memories/shards 슬라이딩 윈도우가 payload에서 노트보다 앞에 있으며, ③ `MAX_PROMPT_NOTES=8`이 노트 21개 중 마지막 8개만 렌더 → **언어/시네마틱/네이밍/인과율 규칙이 일반 턴에 모델에 도달하지 않는 별도 문제 발견**(프리픽스와 무관하게 검토 필요).
- **v2 설계 (다음 작업)**: 노트 조립을 안정 우선으로(저작 규칙→바이블→grant/persona→동적 anti-repeat→루트 스티어링), payload에서 슬라이딩 윈도우를 loop 뒤로, 규칙 노트가 실제 렌더되도록 윈도우 정책 수정 → 안정 프리픽스 ~2.4–2.5k토큰 = **2.5-flash 임계(2048) 통과 → 입력비 ~25–30% 절감**. 3.5의 4096은 추가로 계약서(JSON contract) 전진 배치 + 스탯보이스 전문 포함으로도 ~1k토큰 부족 — KO 디렉티브 팩 전체를 시스템으로 옮기는 재설계(품질 QA 필요)가 남은 갭. 주의: gemini-3 계열엔 **9k–17k 프롬프트 구간 캐시 데드존** 보고가 있어([python-genai#2064]) 중후반 턴(9k+)은 적중이 흔들릴 수 있음 — 적용 후 실측으로 확인.
- 3.5 이행 시 별도 마이그레이션: `thinking_budget` → `thinking_level`(둘 다 보내면 400; 현재는 budget=0 단독이라 안전).
- 3.5 절감 대안(캐싱 외): 키비트 턴만 3.5·일반 턴 2.5의 **모델 이원화**(`generate(model=...)` 시임 존재).
- CBT 기본값은 2.5 유지. 3.5 전환은 라이브 플레이 평가(`MODEL=gemini-3.5-flash make api`) 후 프로즈 가치로 판단.
