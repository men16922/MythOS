# CBT P1: 온보딩 · 다회차 변주 · 서사 밀도 · 전투 가독성 — 설계 스냅샷

작성: 2026-07-05. 입력: Audrey #1 (EN, `docs/cbt/CBT_FEEDBACK.md`) + 오너 자가 플레이 7루프
(`CBT_FEEDBACK.md` #2). 두 소스의 지적이 **"첫 세션 이해가능성 + 다회차 유인"** 으로 수렴.
Authority 백로그는 `docs/NEXT_PLAN.md` (이 문서는 설계 근거/상세).

## 트랙 A — 온보딩 (Audrey 4건, 기존 P1 확정분)

1. **전투 예고 (jump-scare 제거)**: 전투로 이어지는 선택지에 위험 배지(⚔ 충돌 위험) + 전투 진입 시
   1비트 전환 인터스티셜(기존 컷신 머시너리 재사용, "수색등이 이쪽을 향한다…"). 보스 빌드업 규칙의 일반화.
2. **첫 전투 인터랙티브 튜토리얼**: 최초 전투 1회 한정 오버레이 — 이동→공격→스킬→방어 4스텝 하이라이트,
   각 스텝은 실제 그 행동을 해야 진행. `localStorage` + meta로 1회만.
3. **점진 공개**: 첫 루프 턴 0-2는 서사+선택지+게이지만; 지도/CHARACTER 탭은 첫 사용 시점에 배지로 유도;
   DEV LOG 기본 접힘. (부트 화면은 시뮬레이터 게이팅으로 이미 경량화됨.)
4. **서사 disjoint**: 규칙-잘림 버그 시기 피드백이라 3.5+다이어트 스택 재검이 먼저 (사인오프 EN 루프).
   잔존 시 트랙 C의 연결성 작업과 합류.

## 트랙 B — 다회차 변주 (오너: 7루프에 카이까지만 만남)

**진단**: 만남 사이드 아크는 지도당 최대 2 앵커를 ~8개 아크 풀에서 시드-랜덤 선발 → 특정 동료 아크가
뜰 확률 ~25%/판, 게다가 떠도 경유하지 않으면 소실. 언락(한/수아/태오)은 이미 충족 — **병목은 노출**.

1. **만남 아크 보장 슬롯**: 지도 생성 시 "언락됐지만 아직 못 만난 동료"의 만남 아크가 있으면 **최소 1개
   강제 포함**(잔여 슬롯만 랜덤). `weave_side_arcs`에 우선 버킷 추가 — 결정론 유지(시드 셔플은 버킷 내).
   완료 기준: 언락+미만남 동료 존재 시 지도에 해당 아크 ≥1 (유닛테스트).
2. **Loop 2+ 오프닝 변주**: 1회차는 현행 5컷 튜토리얼 유지. 2회차부터:
   - **재진입 단축 오프닝** (5컷→1컷 + "루프 재개" 프레이밍, 이미 아는 플레이어에게 5컷 반복은 이탈 요인),
   - **변주 오프닝 풀** (디렉티브 레이어, 시드/메타 선택): 야시장에서 깨어남(린위에 훅) · 추적 한복판에서
     시작(전투 조기) · 동료 신호로 시작(미만남 동료 훅) — 기존 "아키타입별 오프닝" 장기 항목과 통합.
3. **루프 모디파이어 ("이번 루프의 변주")**: 루프 시작 시 시드 선택 1개를 배너로 명시 — 예: 순찰 강화
   (전투 빈도↑ 보상↑) · 시장 활황(교환비↓) · 신호 교란(지도 호라이즌↓ 단서 보상↑). 데이터 주도 테이블
   (`scenario.json loop_modifiers`) + 결정론 적용. 다회차 체감 랜덤성의 핵심 장치.

## 트랙 C — 노드 밀도/연결성 (시간끌기 체감 + 태오 뜬금 참전)

1. **no-op 턴 가드**: 비분기 턴이 플래그/스탯/아이템/관계 델타 0으로 끝나면 다음 턴 프롬프트에
   "세계 반응 에스컬레이션" 지시 주입(추적 조임/단서 노출/NPC 개입). 반복 시 강제 이벤트. — "선택이
   반영 안 되는 느낌"의 직접 대응. (획득 토스트가 이미 보상 가시화의 첫 조각.)
2. **레이어 페이싱 노브**: 비앵커 노드의 인레이어 서사 턴 수 상한(2→1) 검토 — `[manual]` 밸런스 판단.
3. **참전 예고 규칙 (태오 케이스)**: 동료가 전투에 등장하려면 **이 루프에서 선행 비트 필수** — met_* 획득
   또는 "합류 신호" 인터스티셜(컷신 머시너리, 전투 직전 스테이징). 엔진 게이트 + 예고 비트 자동 삽입.
   세션 메모리 비트 원장에 companion-ref 기록 → 프롬프트가 후속 장면에서 콜백.
4. **SFX 큐**: LLM 대사 내용이 아니라 **결정론 신호**로 트리거 — scene_type/전이(전투 진입=경보,
   아이템 획득=픽업음, 컷신=스팅, 긴장 급등=드론음). 서버 스냅샷에 `sfx_cue` 필드(규칙 파생) +
   클라이언트 `playSfx` 매핑. 기존 오디오 에셋 인벤토리 확인 후 부족분만 생성(agy).

## 트랙 D — 전투 가독성/레이아웃 (스킬 불명 + 보드 협소)

1. **스킬 카테고리 배지 + 기대효과 라인**: 액션 바 버튼에 이동기/버프/공격 뱃지와 한 줄 효과
   ("신호도약: 이동 4칸 · 데미지 없음" / "엄호 노이즈: 아군 방어 +3, 1라운드"). 데이터는 이미 존재
   (role/tags/effect) — 렌더만.
2. **상태 칩**: 버프/디버프를 보드 유닛 + 로스터 카드에 칩으로 표시 (DEF+3 · 1턴) — "엄호 노이즈가 뭘
   했는지 모름"의 직접 해결.
3. **보드 확대 레이아웃**: 전투 그리드를 재배치 — TACTICAL BOARD 상단 전폭, PARTY/ENEMY 로스터+로그를
   하단 행으로. (browser-observable → AGY live-QA 스크린 대상.)
4. **지형 오브젝트 가독화**: 엄폐 보너스는 이미 실기능(+3/+6, `engine.py`) — 문제는 비가독. 엄폐 타일에
   방패 아이콘/툴팁(타일 인스펙터 확장), 장식 오브젝트와 시각 구분, 전투 내레이터가 엄폐 언급하도록 지시.
5. **과부하 일격 밸런스**: 전맵 사거리 치트 체감 — `[manual]` 결정 항목 (제안: 사거리 5 + 쿨다운 +1,
   또는 집중 비용 상향). 결정 후 `[auto]` 반영.

## 트랙 E — 캐릭터 고유 스킬 (특성화 부족 + 보스 전용기)

**진단**: 현재 스킬 풀은 플레이어/동료가 공용 풀에서 조합되는 구조라 캐릭터 개성이 전투에서 안 읽힘.
IX 보스도 일반 적 패턴의 스탯 강화판에 가까움.

1. **동료 시그니처 스킬 1개씩** (데이터 주도, `combat.allies[id].signature`): 세린=엄호 특화(예:
   "차폐 필드" — 인접 아군 2명 방어+2), 카이=기동(예: "백도어 루트" — 아군 1명 즉시 재배치),
   린위에=원거리 EMP(스턴 1턴 — **트랙 F의 EMP 스턴 구현과 공유**), 한=지름길(이동+2 파티 버프),
   수아=해킹(적 집중 -2), 태오=수호(도발+피해감소). 스킬 아이콘/이펙트 스프라이트는 codex(스펙 정제)
   → agy(Imagen 생성, 기존 아이템 아이콘 스타일 스펙 재사용) 파이프라인.
2. **IX 보스 전용 스킬 2-3개 + 페이즈**: 예: "최적화 프로토콜"(맵 타일 봉쇄), "명단 소거"(최저 HP 대상
   고정 피해 + 예고 1턴 — 회피 가능한 텔레그래프), HP 50% 페이즈 전환 시 패턴 변경. 텔레그래프는 트랙 A1
   예고 문법과 톤 통일.
3. **밸런스 가드**: 시그니처는 기존 balance invariant(runs=0 baseline no-op) 안에서 — 신규 스킬은
   유닛테스트로 수치 잠금, `make validate-content`에 스킬-참조 무결성 포함.

## 트랙 F — (기존 발견 연계) EMP 수류탄 스턴 구현

`effect: "stun"`이 엔진 미구현(장식품 상태) — E1 린위에 시그니처와 같은 스턴 상태를 한 번에 구현:
`stunned_turns` 컴바탄트 필드 + 턴 스킵 + 상태 칩(D2) + 아이템/스킬 양쪽에서 사용.

## 우선순위/순서 제안

- **P1-A (착수 1순위)**: A1-A3 + D1-D2 (온보딩+스킬 가독 — 두 테스터 공통 최다빈도, 전부 객관 검증 가능)
- **P1-B**: B1 보장 슬롯(작음) → B2 오프닝 변주 → B3 모디파이어
- **P1-C**: C3 참전 예고 → C1 no-op 가드 → C4 SFX → D3 레이아웃 → D4 지형
- **P1-D**: F 스턴 기반 → E1 시그니처 6종(+아이콘 파이프라인) → E2 보스 전용기/페이즈
- `[manual]` 결정 대기: C2 페이싱 노브 · D5 과부하 일격 · (기존) ally-writeback
- 검증: 각 슬라이스 `make check` + AGY live-QA; 튜토리얼/점진공개는 EN 신규 계정 기준 스크린 검증;
  E/F는 전투 유닛테스트 + 100-seed 밸런스 스모크.
