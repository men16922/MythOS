# Mythos 2.0 — "Signal Run" (design + build contract)

Date: 2026-10-10 · Owner mandate: "rebuild everything if needed; fun D → S; ship by morning".
Branch: `mythos-2.0`. Classic (1.x) stays reachable at `/?classic=1` for comparison.

## 0. Why 1.x is D-level (measured, see audit in PROGRESS_LOG 2026-10-10)

1. Every click waits 10–60 s on an LLM wall of text; choices are flavour ("gaze at the neon").
2. Choice consequences are invented by the LLM (no defined cost/reward); 4 of 5 turns have none.
3. A run is ~46 narrative turns / ~1 h; you cannot fail before the boss (thresholds suspended).
4. Combat: 2–4 rounds, basic-attack spam wins 93–100 %, moving consumes the whole turn, enemies have no telegraphs.
5. Build = flat +2..+4 stat boons; no new abilities inside a run.
6. UI is a dev console: 5 jargon gauges, 7-field choice cards, raw ids.

## 1. Pillars (what S-level means here)

1. **Every input is a decision with a visible consequence.** No flavour-only options. Odds, costs and
   telegraphs are always on screen before you commit.
2. **Perfect-information tactics** (Into the Breach): enemies telegraph exactly which tiles they will hit;
   you dodge, block, push enemies into each other, into void, into their own attacks.
3. **Build-crafting** (Slay the Spire): deck of Protocols (cards), Implants (relics), companions who add
   their own cards. Every run plays differently.
4. **Fast loop, real stakes**: a run is 3 acts × 8 nodes ≈ 30 min. Death is real; the loop resets.
5. **The AI GM reacts, never blocks**: authored text appears instantly; the GM's personalised line streams
   on top (events, IX taunts, run chronicle) and adjudicates the free-text **Improvise** action inside
   hard engine bounds.
6. **Meta progression with narrative** (Hades): Echoes buy unlocks in the Archive; IX remembers how you died.

## 2. Run structure

- Loop start (Archive hub) → pick Archetype (+ starting companion once unlocked) + Paradox level.
- 3 Acts. Each act map: 7 rows of nodes + boss row (row 7). 3–4 columns, 1–2 edges per node, StS-style.
  - Row 0: all `combat`. Row 6: all `rest`. Row 3: at least one `treasure`. Elites only rows 2–5.
    ≥1 `shop` in rows 2–5. Mix target: combat 45 %, event 22 %, elite 10 %, shop 8 %, rest 7 %, treasure 8 %.
- Act 1 "C-17 블랙아웃 / C-17 Blackout" (streets) · Act 2 "야시장 하층 / Undercity Market" (undercity/industrial)
  · Act 3 "ARK 첨탑 / The ARK Spire" (spire). Bosses: Act 1 HAETAE suppression tank (suppression-mech art),
  Act 2 Echo Eater (glitch-wraith art), Act 3 Administrator IX (3 phases).
- Se-rin joins in the Act 1 opening event (loop 1 always; later loops: the chosen starting companion).
  A recruit event at the start of Act 2 offers 2 unlocked companions (party max = connector + 2).
- After the Act 3 boss: **final choice** among endings (gated by bonds/codex/trace) → ending screen.
- Death → "Forced Erasure" ending → Echo tally → Archive.

## 3. Resources

- **HP** (connector) — run ends at 0. Companions have their own HP; at 0 they are *downed* for that fight
  (their cards in hand become unplayable) and return at 1 HP afterwards.
- **Credits ₵** — fights 12–20, elites 30–40, boss 60; shop currency.
- **Trace** 0–100 (IX detection). Gained: +3 per node entered, "loud" cards, greedy event options.
  Tiers: 0–32 Quiet · 33–65 Alert (enemies +15 % HP) · 66–99 Hunted (+25 % HP, +1 damage) · 100 PURGE
  (every fight adds a purge drone). Reduced at rest (scrub), shop (scrub), some events/cards.
- **Stats** STR AGI INT CHA OBS (1–10) — only for event checks. Chance% = clamp(5, 95, 50 + (stat − dc)·10).
- **Consumables** (max 3) — free to use in combat (grenades, nanopatch, stims; existing item icons).
- **Echoes ◈** — meta currency: +1 per node cleared, +4 elite, +12 boss, +25 victory, ending bonus.

## 4. Combat rules ("Breach Protocol")

Board 7×5 (`GRID_W`/`GRID_H`). Party deploys x 0–1, enemies x 4–6. Tiles: floor/cover/hazard/void (types.ts).

Turn loop (ITB order — telegraphs are always visible during the player turn):
1. **Combat start**: place units, every enemy picks and telegraphs an intent, shuffle deck, start player turn 1.
2. **Player turn**: energy = maxEnergy (3), draw to handSize (5). Party block is cleared at the start of the
   player turn; `guard` adds block. Every party unit may **move once** (BFS ≤ `move`, orthogonal, may pass
   through allies, not through enemies/cover/void; shocked units cannot move). Moving is free and can be
   undone until a card is played. Cards cost energy; the origin of a card is the selected unit (`owner: any`)
   or its fixed owner. Unplayable while owner is downed.
3. **End turn**: discard hand (except `retain`), then the **enemy phase**:
   a. Enemy block clears. Each living enemy in uid order fires its intent if `windupLeft == 0` (else
      decrement). Shocked enemies fizzle. Relative patterns resolve from the enemy's CURRENT position and
      facing; damage hits WHATEVER unit stands on the tiles (friendly fire is a feature).
   b. Burn ticks, hazard tiles deal 2 to units standing on them, statuses decrement, reinforcements arrive.
   c. Each enemy without a pending windup moves (AI by `ai`) and telegraphs a new intent (sets `facing`).
   d. Win/lose check → next player turn.
4. **Damage**: amount (+mark, −2 if attacker weak, −armor) → block absorbs first → hp. Bump (push blocked
   by unit/cover/edge/void-for-party) = 1 damage to both (+implant bonus). Enemy pushed into void = destroyed.
5. **Win**: all enemies dead (or `survive` N turns). **Lose**: connector hp 0. Bonus objective (optional,
   shown on the HUD): turn limit / untouched / environment kills / protect → extra card choice or credits.

Numbers (balance budget): connector 32–36 HP, companions 18–24. Energy 3, hand 5, move 3.
Card value per energy ≈ 5 dmg single target, or 6 block, or 3 dmg + push. Push ≈ 2 dmg of value.
Act 1 enemies: minions 5–7 HP, normals 9–14 HP / 2–3 dmg, elites 28–36 HP / 4–5 dmg, boss ~80 HP.
Act 2 ≈ ×1.4, Act 3 ≈ ×1.8, IX ≈ 160 HP over 3 phases. A normal fight should take 3–5 player turns.

## 5. Content quotas (content agent)

- Cards ≥ 60: 3 archetype starter sets (10 each, incl. 2–3 archetype-exclusive), ≥ 30 pool cards
  (common 14 / uncommon 11 / rare 7), 6 companions × 3 cards (2 base + 1 bond), 3 junk ("Static", "Trace Bug",
  "Corrupted Echo"). Every card uses the existing icons in `resources/neo-seoul/skills|items|status/`.
- Enemies ≥ 14 (reuse 9 sprites at different tiers/colours), 3 bosses with phases. Every move telegraphs.
- Encounters: per act ≥ 6 normal, 3 elite, 1 boss; hand-placed terrain; ~40 % with a bonus objective.
- Implants ≥ 30 (starter 3, common 10, uncommon 9, rare 6, boss 3, shop 3).
- Consumables ≥ 8. Events ≥ 24 (8 per act + the Act 1 opening + Act 2 recruit), 2–4 options each, real costs.
- Companions 6 (Se-rin, Tae-o, Han, Su-ah, Kai, Lin-yue). Archetypes 3 (Ghost, Data Smuggler, Echo Collector).
- Meta unlocks ≥ 20 (2 archetypes, 5 companions, 3 card packs, 2 implant packs, ≥ 8 threads), Paradox 1–5,
  Lore ≥ 15, Endings 4 (Safe Refuge, Code Rewrite, Noble Sacrifice, Forced Erasure), IX lines ≥ 16.
- All text bilingual {ko, en}. Korean is the authored voice (screenplay tone: concrete, short, no repeated SF jargon).

## 6. Engine API (public names — UI and other modules code against these)

`moveUnit(c, C, uid, to)`, `undoMove(c)`, `selectableTargets(c, C, cardUid, originUid): TargetOption[]`,

`endTurn(c, C)`, `intentInfo(c, C, uid)`, `threatMap(c, C)`, `cardFace(def, upgraded)`.
`TargetOption = { pos?: Pos; dir?: Dir; tiles: Pos[] }` (tiles = everything the play affects, for highlighting).
`CombatPreview = { units: { uid; hpBefore; hpAfter; blockAfter; dies; to?: Pos }[] }`.
Unit uids: `connector`, companion id (`se_rin`…), enemies `e1`, `e2`…, neutral `neutral`.

`engine/run.ts` + `map.ts` + `meta.ts` (run agent): `newRun`, `enterNode`, `updateCombat`, reward/event/shop/

the module headers; `engine/index.ts` re-exports everything.

## 7. AI GM (backend agent)

- `POST /api/v2/gm/narrate` `{kind: 'event'|'ix_loop_start'|'chronicle'|'boss'|'bond', lang, context}` →
  `{text, source: 'llm'|'fallback'}`. ≤ 3 sentences (chronicle ≤ 6). Hard timeout 12 s; client always has an
  authored fallback and never waits on it.
- `POST /api/v2/gm/improvise` `{lang, event, action, stats, act}` → `Improvisation` fields
  (stat, dc 3–9, reward ∈ {credits, heal, card, trace_down, implant}, risk ∈ {hp, trace, credits}, texts).
  Server validates/clamps; implant reward only when dc ≥ 7. Deterministic keyword fallback when no LLM.
- `GET/PUT /api/v2/profile`, `GET/PUT/DELETE /api/v2/run` — JSON blobs per player id (Postgres table
  `v2_saves`, in-memory fallback). Client mirrors to localStorage and works offline.
- Providers: reuse `mythos_narrative` (Ollama locally, Vertex Gemini in cloud); plain text, no JSON parsing
  except improvise.

## 8. UX (ui agent)

Screens: Title · Archive (meta hub) · Loop setup · Act intro · Map · Combat · Reward · Event · Shop ·
Safehouse · Treasure · Card pick · Final choice · Ending/Run summary. Persistent top bar in a run:
HP, credits, Trace meter (tiered colour), party portraits with HP, implants row (hover tooltips),
consumables, deck viewer, act/floor, settings.

Combat screen: board centre (backdrop image, tile grid, unit sprites using idle/attack/hit/guard art),
intent overlays (red tiles + arrows + damage numbers, windup = pulsing amber), hover a card → highlight
legal targets; hover a target → exact preview (damage numbers, skull on lethal, push arrows); hand of cards
fanned at the bottom, energy orb, End Turn, draw/discard counts, bonus objective chip, unit tooltip.
Juice: card lift/fly, floating damage numbers, hit flash (sprite swap), screen shake on big hits, death
dissolve, enemy attack lunge, SFX + BGM from `resources/neo-seoul/audio`. Keyboard: 1–9 cards, E end turn,
Z undo move, Esc cancel. Readable at 1280×720 and down to 900 px wide.

Visual language: dark neo-noir terminal (cyan/green UI, magenta/red threats, amber warnings), big readable
type, no raw ids, no developer labels, Korean/English toggle.

## 9. Testing & acceptance

- `node --test` engine tests (`make test-v2`), wired into `make check`. Python tests for `/api/v2`.
- Headless sim (`engine/sim.ts`): a greedy bot plays N seeded runs. Targets: starter deck vs Act 1 normal
  fights win ≥ 95 % with avg 3–5 turns; basic-attack-only bot must do clearly worse than the greedy bot;
  greedy bot full-run win rate 15–45 % at Paradox 0 (skill matters, not a coin flip).
- Browser play-through of a full Act 1 (and boss) on the local server before calling it done.
