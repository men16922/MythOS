**오너 지시("추천안대로 알아서 수행")에 따라 기본값 수신 대행으로 3단계까지 만들었다. 오너가 해 보고 뒤집을 수 있다.**

- 경쟁안: **《역류》**(Argon). 규칙 "점등/암전", 병렬 3막. 손맛이 압도적으로 좋을 때만 이쪽으로 바꾼다. 그림 34장, 규모 L이다.
- 《청산선》(Claude)은 탈락. 이유는 §2.

코드와 450판 시뮬로 대조했다. 기준선은 표준 202/450 = 44.9 %로 기존 기록과 일치한다.

## 2. DLC 2 판단

| | 명단 밖의 사람들 (Astra) | 역류 (Argon) | 청산선 (Claude) |
| --- | --- | --- | --- |
| 새 규칙 | 접점 위 유닛이 시민 대신 맞는다 | 칸마다 점등/암전 | 에너지 선대출, 다음 전투에 상환 |
| 판단 | 높음. 죽일 적과 쓸 적이 갈린다 | 높음 | 중 |
| 장면 | 높음. "적을 밀어 넣어 대신 맞게 했다" | 높음. 불이 꺼지는 순간 | 낮음 |
| 핵심 동사 | 밀치기를 강화 | 밀치기 + 시야 | 자원, 밀치기와 무관 |
| 예고 기둥 위험 | 낮음 | **높음**. 어두운 화면이 붉은 예고를 가린다 | 낮음 |
| 그림 | 2장 이내 | 34장 | 10장 |
| 규모 | M~L | L | M |

- **명단 밖의 사람들을 추천한다.** 이 게임의 핵심 동사인 밀치기를 가장 잘 살리고, 그림이 적고, 세계관의 고유성이 가장 크다.
- **역류는 시험한다.** 볼거리는 가장 크지만 예고 가독성이 걸린다. 이 위험은 손으로 해 봐야 안다.
- **청산선은 뺀다.** `debt_clock`·`black_pact`가 이미 "지금 쓰고 나중에 갚기"를 한다. 금지 임플란트 하나로 충분한 아이디어이고 DLC 머리기사가 되지 못한다.

## 3. 1단계: 완료 (2026-10-31, `main`, 운영 미반영)

오너 지시 "결과 나오면 추천안대로 수행"에 따라 실행했다. 프로토타입 외에는 그림을 쓰지 않았다.

| 항목 | 내용 |
| --- | --- |
| 봇 측정 수정 | 궁극기 평가에 카드와 같은 템포 항 추가. 게임 규칙 변경 없음 |
| 진화 찾기 | 짝이 되는 카드·임플란트의 보상 등장 가중치 ×3, 보상에 작은 ✦ 표시. 결과는 비밀 유지. 시작 카드 조합은 제외 |
| 듀오 찾기 | 영입 장면에 현재 동료의 듀오 짝이 있으면 한 자리를 보장. 봇도 듀오를 출격시킴 |
| 보호 보상 문구 | "★ 보너스 목표 달성" 대신 지킨 대상의 이름 표시 |
| 후반 목표 변주 | `a4_n1_returns`, `a6_n2_drafts` 호위, `a5_n2_compactor`, `a6_n2_erasers` 4턴 생존. 조우 수와 그림 추가 없음 |
| 난이도 보정 | `enemyHpPct` 12 → 13 |
| 프로토타입 | 샌드박스 전용 `proto_relay`, `proto_blackout`. 일반 런에서 닿을 수 없고 테스트로 보장 |

| 측정 (기준 시드) | 전 | 후 |
| --- | --- | --- |
| 표준 혼합 봇 | 202/450 = 44.9 % | **200/450 = 44.4 %** |
| 비기본 진화가 나온 판 | 51/450 | **109/450** |
| 딥 시그널 혼합 봇 | 45/150 = 30.0 % | 41/150 = 27.3 % (노이즈 범위) |
| 듀오 발동 판 | 8/450 | 8/450 (변화 없음) |

**듀오는 봇 기준으로 늘지 않았다.** 신규 프로필은 쌍 자체가 드물고, 전체 해금 프로필도 150판 중 쌍 5판, 발동 0판이었다. 사람의 영입 선택은 봇과 다르지만, 이 숫자로 효과를 주장할 수 없다. 다음 수정 후보는 봇이 아니라 영입 화면에서 짝을 알려 주는 것이다.

## 4. 2단계: 오너 판정

샌드박스 주소 두 개로 각 5분이면 된다. 소리는 필요 없다.

- `/?sandbox=combat&mute=1&enc=proto_relay`
- `/?sandbox=combat&mute=1&enc=proto_blackout`

**폐기 기준**

| 프로토타입 | 이 중 하나면 폐기 |
| --- | --- |
| 수신 대행 | 실제 수신자를 오해함 / 정답이 늘 같은 적 고정 / 처치를 미루는 것이 지루함 |
| 암전 | 어두운 칸이 붉은 예고를 가림 / 불을 끄기보다 그냥 카드를 내는 편이 재미있음 |

**프로토타입의 한계.** 암전에서 적 머리 위 예고 숫자는 ±2가 반영되지 않는다. 왼쪽 패널 예상 피해와 실제 피해에는 반영된다. 원안의 "직선탄 은신"은 공격 −2로 단순화했다. 수신 대행은 연결선 없이 점선 칸으로만 표시한다.

## 5. 3단계: 선택 후 제작

**구현됨 (2026-10-31, `main`, 운영 미반영).** 아래는 원래 계획이고, 실제 구현은 다음과 같다.

- 첫 탈출 뒤 런의 2막 지도에서 가장 이른 사건 노드에 「영업 종료」가 배치된다. 데일리에는 없다. 풀에 넣으면 신규 런의 승률이 흔들려(200 → 208/450) 굴리지 않고 배치한다.
- 들어가면 이번 막의 다음 일반 전투 3개가 수신 대행 전투 `outside_serving`, `outside_pickup`, `outside_door`로 바뀐다.
- 마지막 은신처 자리에 결말 사건이 나온다. 아무도 잃지 않으면 「한 그릇」, 아니면 「닫힌 배식대」. 보상은 같아서 슬픔이 수치 벌칙이 되지 않는다.
- 신규 적·카드·재화 0, 신규 스틸 2장(Codex image, 결말 2종은 같은 그림).
- 측정: 신규 프로필 200/450 = 44.4 %로 변화 없음. 첫 탈출 프로필에서 구간 진입 강제 시 209/450, 거절 시 210/450. 강제 측정에서도 봇은 68/450판만 도달했다. 평균 시민 1명만 살렸고 봇은 적을 접점에 밀어 넣지 못한다. 이 수치로 재미를 말할 수 없다.

**수신 대행이 통과하면** (M~L)

1. 접점 조우 3개, 2막 선택 구간 하나. 기존 전투 3곳과 사건 2곳을 교체하고 총 노드 수는 유지한다.
2. 사건 도입 2개, 결말 2변형, 스틸 2장 이내.
3. 예고 연결선과 대상별 미리보기. 설명이 작은 화면에서 안 되면 규칙을 폐기한다.

**암전이 통과하면** (L) 병렬 3막, 적 12, 카드 12, 사건 12, 구역 3, 그림 34장. 먼저 예고 숫자 ±2 표시부터 해결한다.

**둘 다 탈락하면** DLC 2는 보류하고 4단계로 간다.

## 6. 4단계: 그다음 후보

재미 기준 순서다. 착수 시 각각 다시 판단한다.

1. **후반 청구 장면**: 앞의 선택이 후반에 돌아온다. 린위에 빚 한 갈래로 먼저 시험한다.
2. **5·6막 구역 + 1.0 반전 물증**: 지금 5·6막에는 구역이 없다. 구역 4곳, 그림 4장.
3. **아키타입 진화 5종**: 진화가 전부 공용 카드라 직업 정체성이 없다.
4. **보스 페이즈 보드 재편**: 4·5막 보스 반피에 지형을 다시 쓴다.
5. **`scrapborn`과 부품 연결**: 이름만 있고 효과가 없다.
6. **변칙 조합기 시너지 쌍**: 작은 발견 포인트.

**W2 공모전 트랙**(Paradox 10 실구현, 습관 읽는 IX, 절차적 사건)은 공고가 나면 앞당긴다. 2026-10-31 검색에서는 찾지 못했다. **12-01에 Devpost를 다시 확인한다.**
