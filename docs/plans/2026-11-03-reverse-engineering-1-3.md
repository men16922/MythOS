# 리버스 엔지니어링 분석: 1~3순위

작성일: 2026-11-03 · 작성: Claude · 근거: `docs/plans/2026-11-01-next-steps-plan.md` 4단계 10번 (분석만, 제작은 오너 판정 뒤)

공개된 리뷰·가이드·위키 기준의 분석이다. 게임을 직접 플레이하지 않았고, 코드나 에셋은 보지 않았다. 각 게임의 Mythos 현황은 2026-11-03 `main`(`5c52a66`) 코드에서 확인했다.

## 요약

| 순위 | 게임 | Mythos에 이미 있는 것 | 빈 곳 | 제안 | 크기 |
| --- | --- | --- | --- | --- | --- |
| 1 | Across the Obelisk | 동료 레벨 1~5, 3·5레벨 보너스 | 레벨업이 자동이라 빌드 선택이 없다 | 3·5레벨에 둘 중 하나 고르기 | S |
| 2 | Cobalt Core | 동료 카드 보상 가중치 2.5배, 분대 전술 12종 | 조합에 따라 플레이가 실제로 달라지는지 측정한 적이 없다 | 먼저 측정, 차이가 작으면 동료 카드 쪽을 손본다 | S (측정) |
| 3 | Tactical Breach Wizards | 이동 되돌리기, 항해사 전용 턴 되감기 1회 | 카드를 잘못 내면 되돌릴 수 없다 | 새 정보가 없는 카드는 되돌리기 허용 | S~M |

**2번 측정 결과 (2026-11-03, 같은 날 처리):** 봇이 2막 영입 장면에서 늘 혼자 갔다. 동료 가치 10이 "혼자 간다" 묶음(최대 체력 +4, 체력 +4, 40₵, 추적 −10 ≈ 16)보다 낮았기 때문이다. 그래서 4막에 닿은 딥 판의 77 %(114/148)가 동료 한 명이었고, 분대 전술은 7판에서만 나왔다. 11-01 이후의 파티·성장 밸런스는 사실상 동료 한 명 기준이었다. 봇을 고치자(빈 자리면 20, 대기석이면 6) 일반 39.1 → 50.4 %가 되어, 2·3막을 다시 올렸다(아래 `PROGRESS_LOG.md`). 고친 뒤 딥 4막 이상 148판 중 분대 전술 판은 32판으로 늘었지만 표본이 작아 전술별 승률 범위는 아직 판단하지 않는다. 카드 겹침 측정은 시뮬레이터가 낸 카드를 기록하지 않아 하지 못했다.

**권장 순서:** 2번 측정 → 1번 프로토타입 → 3번 프로토타입. 2번은 판정 없이 바로 할 수 있는 측정이고, 그 결과에 따라 1번의 선택지를 무엇으로 채울지 정해진다.

## 1. Across the Obelisk — 레벨업 선택

| 항목 | 내용 |
| --- | --- |
| 구조 | 4인 파티, 인물별 덱. 레벨업마다 두 선택지 중 하나를 고르고, 그 선택이 인물의 플레이 방식과 덱 방향을 정한다. 플레이어 토론에서는 인물의 개성이 시작 덱보다 레벨업 선택에서 나온다고 본다. 판 사이에는 별도의 특성 트리(36점, 언제든 초기화)가 있다 |
| Mythos 현황 | `engine/companionLevel.ts`: 승리로 경험치를 얻고 성장 포인트로 바로 올릴 수도 있다. 레벨마다 체력 +2, 상위 두 능력치 +2/+1. 3레벨 방어 +3, 5레벨 모멘텀 +15는 고정이다. 덱은 공용이고 카드마다 주인(`owner`)이 있다 |
| 가져올 것 | 3레벨과 5레벨에서 그 동료의 역할에 맞는 두 보너스 중 하나를 고른다(지금의 고정 보너스를 한쪽 선택지로 남긴다). 동료 한 명당 한 판에 최대 두 번, 한 번 누르면 끝나는 선택 |
| 가져오지 않을 것 | 인물별 덱(관리 피로), 판 사이 특성 트리(Archive와 겹친다), 매 레벨마다 선택(동료 3명 × 4회 = 12번은 피로가 크다) |
| 측정 | 봇은 두 선택지를 번갈아 고른 블록과 고정 블록을 같은 시드(정규 블록, 450판 이상)로 비교한다. 혼합 봇 승률 차이가 ±2점 안이어야 한다. 선택지 하나가 늘 이기면(블록마다 같은 쪽이 3점 이상 우세) 그 선택지를 고친다 |
| 오너 판정 | 샌드박스에서 같은 동료를 두 선택지로 한 번씩 써 보고, 차이가 손에 느껴지는지 본다 |

## 2. Cobalt Core — 조합이 판의 색을 정한다

| 항목 | 내용 |
| --- | --- |
| 구조 | 승무원 3명이 시작 덱과 그 판에 나오는 카드 풀을 정한다. 이동(회피)이 공격과 방어를 겸한다. 어떤 조합으로도 이길 수 있지만 이동 담당이 없으면 크게 어려워진다는 플레이어 평이 있다 |
| Mythos 현황 | 보상에서 출격한 동료의 카드가 2.5배로 나오고(`engine/run.ts`의 `COMPANION_CARD_WEIGHT`), 대기 중인 동료의 카드는 전투에서 빠진다. 4막부터 세 명이 출격하고, 출격 조합이 분대 전술 12종 중 하나가 된다(`engine/squad.ts`). Cobalt Core의 핵심 구조는 이미 있다 |
| 빈 곳 | 조합을 바꾸면 실제로 다른 판이 되는지 데이터가 없다. 분대 전술이 능력치 보너스뿐이라 수치 차이로만 끝날 수 있다 |
| 가져올 것 | 측정 기준: 조합마다 가장 많이 낸 카드 5장이 얼마나 겹치는지, 분대 전술별 승률 범위 |
| 가져오지 않을 것 | 1차원 보드, 함선 선택 계층(원형이 이미 그 역할이다) |
| 측정 | `simulateRun`으로 4막 이후의 조합별 블록을 돌려 (a) 분대 전술 12종의 승률 범위, (b) 조합 간 상위 카드 5장의 겹침을 기록한다. 기준: 승률 범위가 10점 안이고, 서로 다른 조합의 상위 카드 겹침이 평균 2장 이하. 겹침이 크면 다음 후보는 출격 동료 카드 가중치를 올리거나 전술 하나에 카드 효과 하나를 붙이는 것이다(같은 시드로 A/B) |
| 오너 판정 | 측정 결과만 보고, 손볼 필요가 있을 때 판정한다 |

## 3. Tactical Breach Wizards — 확정 전 되돌리기

| 항목 | 내용 |
| --- | --- |
| 구조 | 결과를 미리 보여 주고, 턴 안에서는 행동 하나씩 얼마든지 되돌릴 수 있다. 다음 턴으로 넘기면 확정된다. 이야기 안에서는 예지력을 가진 인물로 설명한다. 개발자는 모든 수를 따져 볼 수 있게 하는 것이 어렵지만 더 재미있다고 말한다 |
| Mythos 현황 | 카드나 소모품을 내기 전까지는 이동을 되돌릴 수 있다(`undoMove`). 항해사 원형(DLC 3)만 턴 전체를 한 번 되감는다(`rewindTurn`, 같은 패와 주사위 그대로). 적 행동 예고는 이미 Into the Breach 방식이다 |
| 가져올 것 | 새 정보를 드러내지 않은 행동은 되돌릴 수 있게 한다. 카드를 뽑거나 무작위 굴림이 들어간 행동부터 확정된다. 실수로 누른 카드에서 오는 피로를 줄이는 것이 목적이다 |
| 가져오지 않을 것 | 턴 전체를 무제한으로 되감기(항해사의 정체성을 없앤다), 패배가 거의 없는 퍼즐 구조, 고정 스테이지 |
| 위험 | 되돌리기로 미리 보기만 한 결과를 시험해 볼 수 있으면 난이도가 내려간다. 봇은 이미 완벽한 미리 보기로 계획하므로 시뮬레이터로는 측정되지 않는다. 사람이 해 봐야 안다 |
| 측정 | 엔진 테스트: 되돌린 뒤의 상태가 그 행동 직전 상태와 같은지 확인하고, 뽑기나 굴림 뒤에는 되돌리기가 막히는지 확인한다. 실제 UI에서 데스크톱과 390 px 둘 다 확인한다 |
| 오너 판정 | 샌드박스에서 한 판: 피로가 줄었는지, 너무 쉬워졌는지 |
