계획은 "저장 호환을 먼저 증명한다"를 첫 단계로 둔다. 1단계를 끝냈다. 플레이 가능한 모드는 아직 없다.

## 1단계 — 저장 호환 (완료, 2026-11-04)

| 항목 | 내용 |
| --- | --- |
| 자리 | 새 저장 칸을 만들지 않고 프로필 안에 둔다(`MetaProfile.chronicle`). 이미 있는 저장·동기화·512 KB 상한을 그대로 탄다. 서버는 저장 내용을 검사하지 않고 JSON 그대로 보관하므로 서버 변경이 없다 |
| 넘어가는 것 | 원형, 스탯, 배경, 선택 축, 동료 승인, 임무 단계, 세력 평판, 핵심 카드 3장(`engine/chronicle.ts carryOver`). 덱의 나머지는 장마다 다시 짠다 |
| 검증 | 옛 프로필은 그대로 읽히고 `chronicle` 칸이 생기지 않는다. 한 장을 마친 상태가 JSON·프로필 이전을 거쳐 그대로 돌아온다. 잘못된 값은 버리거나 범위 안으로 자른다. 크기는 4 KB 미만(`chronicle.test.ts`) |
