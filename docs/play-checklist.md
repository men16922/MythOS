## 0. 띄우는 법

```bash
make infra-up      # PostgreSQL/Redis 등 의존성 기동
make api           # FastAPI + 빌드된 프론트엔드 서빙
```

브라우저로 **http://localhost:8000** 접속 → 온보딩 하단 **`⚔️ 전투 시뮬레이터`** 아코디언을 펼쳐 조우/동료를 고르고 `전투 시뮬레이션 진입`으로 즉시 교전에 진입한다. (적 4종: `maintenance_drone`/`sentinel_drone`/`enforcer_unit`/`glitch_wraith`, 스킬 5종을 모두 한 번씩 돌려본다.)

## A. 보드 스프라이트 — 위치 & 스케일

- [ ] 전신 스프라이트가 가로/세로 비율 왜곡(stretch) 없이 그려진다.
- [ ] 유닛이 붕 뜨지 않고 **발끝이 셀 바닥(pedestal 링)에 정렬**된다.
- [ ] idle 섬네일 ↔ action 프레임(attack/skill/guard/hit) **교체 시 위치/스케일이 튀지 않는다**(앵커 일관성).
- [ ] 인접 셀에 유닛이 몰려도 서로 심하게 가리지 않는다(z-순서/크기 적절).
- [ ] 적 4종 스케일이 서로 비슷한 체급감으로 보인다.
- [ ] 아군은 우측, 적군은 좌측을 바라보도록 수평 반전이 자연스럽다.

## B. CombatCinema 컷인 — 위치 & 레이아웃

- [ ] 공격자(좌)/피격자(우) 2포스터가 화면 중앙 기준 대칭으로 배치된다.
- [ ] **자가 대상**(자가 가드/엄호 노이즈/패치 프로토콜) 시 우측 본인 카드 중복이 제거되고, 좌측 카드 + 중앙 스킬/시그널 카드가 안정적인 2포스터로 정렬된다.
- [ ] 스킬 아이콘 컷인(`skills/<id>.png`)이 잘림/비율 깨짐 없이 표시된다.
- [ ] 기본 액션 시그널 카드(ATTACK/DEFEND/EVADE)가 텍스트와 겹치지 않고 중앙에 깔끔히 뜬다.
- [ ] 방어 시 `DEFEND` 카드와 우측 `GUARD` 팝업이 중복 출력되지 않는다.
- [ ] 대미지 숫자가 피격 카드 위 적절한 위치에 뜨고 화면 밖으로 잘리지 않는다.
- [ ] 스킬 시전 시 중앙 카드 3D 줌인 + 주변 카드 블러/디밍 집중 연출이 과하지 않게 보기 좋다.
- [ ] 미정의 스킬은 고유 컬러/메타데이터가 담긴 절차적 폴백 카드로 깔끔히 대체된다.

## C. 지속시간 / 타이밍

- [ ] 표준 컷인(~1.95s) / 빠른 컷인(적·회피·방어 ~1.0s)이 너무 길거나 짧지 않다.
- [ ] **타격 프레임(impact)**에 스크린 셰이크 + 피격 글리치(hue-rotate) + 넉백(staggerShake)이 동시에 터진다.
- [ ] 기본 공격 시 공격자 전방 반동 + 투사체(`.cinema-projectile`)가 **비행 후 타격 시점에 도달**한다(도착 전 타격 X).
- [ ] **마지막 일격**(적 전멸/플레이어 사망)에도 컷인이 끊기지 않고 끝까지 재생된 뒤 스토리로 전환된다.
- [ ] 유틸 스킬(`signal_step`/`patch_protocol`) 시전 시 컷인이 생략되지 않는다.
- [ ] 연속 행동 시 컷인 큐가 겹치지 않고 순서대로 재생된다.

## D. 가독성

- [ ] 컷인 오버레이가 떠 있을 때 보드/로그가 의도대로 가려지고, 닫힌 뒤 즉시 복귀한다.
- [ ] 어두운 배경 위에서 대미지 숫자·스킬명·시그널 카드 텍스트 대비가 충분하다.
- [ ] FOCUS 게이지·라운드 표시·적 인텐트 라벨이 전투 내내 읽힌다.

## E. 스킬 아이콘 액션바 (Phase 4 — 함께 점검)

- [ ] 스킬 아이콘 타일이 균일한 크기로 줄맞춤되고, 작은 상세 PNG 대신 심플한 심볼 아이콘으로 과하지 않게 보인다.
- [ ] cost(◆focus/▣item)·range(⌖) 배지, cooldown 오버레이가 아이콘을 가리지 않고 읽힌다.
- [ ] FOCUS 부족/쿨다운 스킬이 dim 비활성으로 구분된다.
- [ ] role별 색상(공격 red / 기동 cyan / 방어 blue / 회복 green / 지원 yellow)이 직관적이다.
- [ ] hover tooltip(이름·역할·사거리·코스트·태그)이 올바르게 뜬다.
- [ ] 아이콘 로드 실패 시 role 글리프 fallback이 깨지지 않는다.
