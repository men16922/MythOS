# MythOS - 전투 연출 및 신규 에셋 플레이 검증 체크리스트

이 문서는 전투 연출 개편(Phase 2~3)과 구글 Gemini 이미지 생성 툴로 제작한 드론 신규 에셋이 정상적으로 작동하는지 검증하기 위한 체크리스트입니다. 

> [!NOTE]
> 핵심 비주얼 컴포넌트 마운트, 상태 동기화, 물리 및 캔버스 드로잉 로직은 Playwright E2E 자동 테스트(`test_e2e_play_checklist.py`)를 통해 100% 검증을 통과했습니다. 아래 체크리스트에서는 자동 검증된 항목을 표시하고, **브라우저 플레이 시 시각적 심미성 확인이 필요한 항목**을 최신 구현 기준으로 조율하여 업데이트했습니다.

---

## 0. 브라우저에서 수동 검증하는 방법 (실행 가이드)

프로젝트를 구동하고 브라우저를 통해 직접 플레이하여 연출을 검증하려면 아래 절차를 따릅니다.

### **방법 A: 로컬 웹 클라이언트 접속 (권장 수동 QA)**
1. **의존성 기동**: 로컬 백엔드 인프라(PostgreSQL, Redis 등)를 백그라운드에 실행합니다.
   ```bash
   make infra-up
   ```
2. **API 및 웹 서버 실행**: FastAPI 백엔드 API 서버를 시작합니다. (Vite로 컴파일된 프론트엔드가 백엔드 스태틱 서비스에 자동 서빙됩니다).
   ```bash
   make api
   ```
3. **브라우저 테스트**: 웹 브라우저를 열고 **`http://localhost:8000`** 에 접속합니다.
4. **전투 직접 진입**: 온보딩 창 하단에 있는 **`⚔️ 전투 시뮬레이터`** 아코디언을 펼쳐 원하는 조우(순찰 매복, 감시 검문 등)를 고르고 동료를 선택한 후 `전투 시뮬레이션 진입` 버튼을 눌러 즉시 교전 캔버스로 진입합니다.

## 2. 브라우저 직접 플레이 수동 QA 체크리스트 (심미성 & 비주얼 확인)

아래 항목은 자동화로 측정할 수 없는 **시각적 자연스러움, 타이밍 싱크, 리소스 품질**을 브라우저 플레이 시 직접 관찰해야 합니다.

### **A. 전투 보드 유닛 스프라이트 배치 (OK - 검증 완료)**
*   [x] **스케일 및 발끝 정렬**:
    *   캐릭터 전신 스프라이트들의 가로/세로 비율이 비틀림(Stretching) 없이 수려하게 노출됩니다.
    *   캔버스 그리드 위에서 유닛들이 붕 뜨지 않고 바닥의 pedestal 링에 발끝 정렬이 매끄럽게 안착되어 있습니다.
*   [x] **진영별 기본 방향성**:
    *   아군 유닛은 **오른쪽(우측)**을, 적군 유닛은 **왼쪽(좌측)**을 바라보도록 방향이 어색함 없이 수평 반전 처리되어 있습니다.

### **B. 특수 스킬 애니메이션 비주얼 퀄리티**
> [!IMPORTANT]
> 전투 시네마 오버레이(`CombatCinema`)가 화면 전체를 가리며 투사되는 연출 특성상, 맵(캔버스) 상에서 백그라운드로 그려지는 이펙트(수축 링, 레이저 Tracer 등)는 수동 QA 시 화면 뒤에 숨으므로 육안으로 확인하기 어렵습니다. (Playwright E2E 상에서 드로잉 호출 로그 검출로 자동 검증을 완료하였습니다).
*   [ ] **신호 도약 (`signal_step` - 이동)**:
    *   [ ] 시전 완료 후 캐릭터 순간이동이 완료된 시점에 맵 상에 그려지는 순간 스파크 및 이펙트 소멸 흐름이 정돈되어 있는가?
*   [ ] **패킷 사격 (`packet_shot` - 원거리)**:
    *   [ ] 총구 플래시(Yellow spark) 연출 및 대상을 향해 뻗어나가는 탄환의 소실 궤적이 프레임상 어긋남 없이 연결되는가?
*   [ ] **엄호 노이즈 (`covering_noise` - 버프/방어)**:
    *   [ ] 펄스 치는 시안(Cyan)색 및 화이트 이중 아우라 링이 맵 캔버스 캐릭터 배치에 어긋나지 않게 렌더링되는가?
*   [ ] **패치 프로토콜 (`patch_protocol` - 힐)**:
    *   [ ] 대상 머리 위로 피어오르는 백색 스파크 효과가 부드러운가?
*   [ ] **과부하 일격 (`overload_strike` - 근접)**:
    *   [ ] 타격 순간 타겟지 타일 위에 흩뿌려지는 황색/적색 이중 타격 스파크 폭발의 파괴감이 전체 타격 연출과 조화로운가?

### **C. CombatCinema 컷인 물리 피드백 및 싱크 (최종 구현 기준)**
*   [ ] **기본 액션 (`ATTACK` / `DEFEND` / `EVADE`) 이미지화 (시그널 미니 카드)**:

*   [ ] **방어(Guard) 시 중복 텍스트 방지**:
