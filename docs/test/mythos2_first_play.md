# Mythos 2.0 — 첫 플레이 안내 (오너용)

최종 갱신: 2026-10-11 아침. 밤사이 새로 만든 2.0을 직접 해 보고 판정할 때 보는 문서입니다.

## 어떻게 켜나

- 터미널에서 `make dev-up`(또는 이미 인프라가 떠 있으면 `make api`) 후 브라우저에서 `http://127.0.0.1:8000/`.
  8000번이 다른 프로그램에 쓰이고 있으면 `MYTHOS_API_PORT=8010 make api` 후 `http://127.0.0.1:8010/`.
  처음 화면이 2.0 타이틀입니다. 이전 게임은 주소 끝에 `?classic=1`을 붙이면 그대로 열립니다.
- AI GM 한 줄 대사는 로컬 Ollama가 있으면 생성되고, 없으면 미리 써 둔 문장으로 대신합니다(게임 진행에는 영향 없음).
  로컬 모델로 보려면 `OLLAMA_MODEL=gemma4:8b-64k OLLAMA_MODEL_STORY=gemma4:8b-64k MYTHOS_API_PORT=8010 make api`.
- 소리가 중요합니다. 스피커/헤드폰을 켜 주세요(첫 클릭 후 음악이 시작됩니다).
- 데이터를 처음부터 보고 싶으면 개발자 도구 콘솔에서 `localStorage` 의 `mythos2.` 로 시작하는 항목을 지우면 됩니다.

## 무엇이 바뀌었나 (한 줄씩)

- 글을 기다리는 게임 → **결정하는 게임**. 모든 선택지에 비용·보상·성공 확률이 먼저 보입니다.
- 전투는 **적이 다음에 칠 칸을 미리 보여 주는** 전술 퍼즐입니다. 피하고, 막고, 밀어서 적끼리 치게 하세요.
- 덱(카드)·임플란트·동료 카드로 매 판 다른 빌드를 만듭니다.
- 한 판은 3막, 약 30분입니다. 죽으면 루프가 끝나고, 모은 에코로 아카이브에서 해금합니다.
- 그림·음악은 2.0용으로 전부 새로 만들었습니다(배경·카드·이벤트·보스·캐릭터 일부, 배경음 18곡).
- AI GM은 사건 장면에 한 줄을 덧붙이고, **자유 행동** 칸에 직접 쓴 행동을 판정합니다. 기다리게 하지는 않습니다.

## 처음 한 판에서 봐 주실 것

1. **처음 5분** — 프롤로그 → 1막 → 첫 전투의 안내 말풍선까지 따라가면 규칙이 이해되는가?
2. **전투 손맛** — 카드 사용, 적중, 밀쳐서 부딪히기, 공허로 떨어뜨리기, 적끼리 맞히기가 시원한가? 소리와 화면 흔들림이 과하거나 약하지 않은가?
3. **선택의 무게** — 지도에서 길을 고를 때, 사건에서 선택지를 고를 때 "고민이 되는가"?
4. **난이도** — 1막 보스(해태)에서 긴장이 되는가? 너무 쉽거나 억울하게 죽지는 않는가?
5. **다시 하고 싶은가** — 죽은 뒤 아카이브에서 해금하고 다음 루프를 바로 누르고 싶어지는가?

## 알아 두면 좋은 것

- 전투 조작: 적이 움직이는 동안 Space·E(또는 턴 종료 버튼)를 누르면 빨리 감깁니다. Alt를 누르고 있으면 위협 지도가 보입니다. 보스를 쓰러뜨리면 남은 소환물도 함께 멈추고 전투가 끝납니다.
- 상단 바의 책 아이콘은 이번 판에서 모은 코덱스 기록 수입니다. 3개를 모으면 마지막 선택에서 'IX의 코드를 다시 쓴다'를 고를 수 있습니다.
- 컴퓨터가 수천 판을 대신 돌려 본 결과: 실수 없는 플레이는 거의 이기고, 실수가 잦으면 2막에서 많이 집니다. 사람의 첫 판은 2막 전후에서 끝나는 것이 정상입니다.
- 실제 서비스(Cloud Run)에는 아직 올리지 않았습니다. 테스터들은 여전히 이전 게임을 봅니다. 올릴지는 판정 후 정하시면 됩니다.
