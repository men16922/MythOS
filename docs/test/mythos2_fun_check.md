# Mythos 2.0 — "돈 내고 할 만한가" 플레이 점검 (오너용)

최종 갱신: 2026-10-30. 자동 테스트로는 알 수 없는 것(재미, 손맛, 다시 하고 싶은지)을 사람이 직접 판정하는 문서입니다.
한 번에 30~40분, 소리를 켜고 하세요. 각 항목은 **정상 / 문제(어디서, 무엇이)** 로만 적어 주시면 됩니다.

## 어떻게 켜나

- 운영 주소에서 바로: 서비스 주소 뒤에 `?demo=<코드>`를 붙이면 로그인 없이 AI 대사가 켜집니다(코드는 `.env`의 `MYTHOS_DEMO_CODES`).
  심사위원이 보게 될 화면과 똑같습니다. 타이틀 오른쪽 위에 "데모 접속" 문구가 보이면 켜진 것입니다.
- 폰으로도 한 번: 같은 링크를 폰 브라우저에서 열어 1막 전투 2번까지.
- 완전히 처음 사람처럼 보려면 브라우저의 시크릿 창을 쓰세요(저장된 진행이 없습니다).

## 1. 처음 10분 — 붙잡는가

- [ ] 타이틀 → 첫 갈림길 사건까지 2분 안에 "무슨 게임인지" 감이 오는가?
- [ ] 첫 전투의 안내 4개를 따라가면 붉은 칸(적 공격 예고) 규칙이 이해되는가? 안내가 다른 글자를 가리지 않는가?
- [ ] 첫 전투가 끝났을 때 "한 판 더"가 아니라 "다음 칸으로"가 자연스럽게 눌리는가?

## 2. 전투 손맛 — 이 게임의 핵심

- [ ] 적을 밀어서 다른 적·벽·불길·전선·공허로 보내는 순간이 시원한가? (소리, 흔들림, 숫자)
- [ ] 한 턴에 "아, 이렇게 하면 둘 다 막을 수 있겠다"는 순간이 한 번 이상 오는가?
- [ ] 억울하게 맞았다는 느낌(예고에 없던 피해)이 한 번이라도 있었는가? 있다면 어떤 적, 어떤 칸이었는지.
- [ ] 보스(해태 또는 주작)에서 긴장이 되는가? 너무 길거나(10턴 넘게) 너무 쉬운가?

## 3. AI가 살아 있는 느낌 — 다른 게임과 다른 점

- [ ] 사건 화면 왼쪽 아래 GM 한 줄이 그 장면·내 선택에 맞는 말인가? 엉뚱하거나 반복되는가?
- [ ] **자유 행동**: 사건에서 선택지 대신 직접 행동을 써 보세요(예: "드론 배터리를 뽑아 던진다"). 판정 결과가 내 문장을 이해한 것 같은가?
- [ ] **NPC에게 직접 말하기**(구역 탐색): 하고 싶은 말을 써 보세요. 상대가 그 사람답게 답하고, 내 말에 맞는 선택지가 굴러가는가?
- [ ] 전투 중 관리자 IX의 통신, 말하는 적의 대사가 거슬리지 않고 분위기를 살리는가? 화면을 가리지는 않는가?
- [ ] 끝난 뒤 연대기(이번 판 요약)가 "내 판"처럼 읽히는가?

## 4. 다시 하고 싶은가 — 구매 의사의 핵심

- [ ] 죽거나 이긴 직후, 아카이브에서 무언가를 해금하고 **바로 다음 루프를 누르고 싶은가**?
- [ ] 두 번째 판에서 첫 판과 다른 선택(다른 동료, 다른 카드 방향)을 해 보고 싶어지는가?
- [ ] 오늘의 시드를 하고 순위표를 보면 내일 또 해 보고 싶은가? 내 기록 옆 방패 표시(서버가 다시 돌려 확인한 기록)가 보이는가?
- [ ] 이 경험에 돈을 낸다면 얼마까지 낼 것 같은가? (0원 / 커피 한 잔 / 인디 게임 한 편 값)

## 5. 폰

- [ ] 상단 바 첫 줄(체력·크레딧·추적도)이 잘리지 않고, 지도가 한 화면에 보이는가?
- [ ] 카드를 누르고 칸을 누르는 조작이 손가락으로 불편하지 않은가?

## 6. 딥 시그널 — 6막 끝까지 한 판

첫 탈출 뒤 접속 설정의 "깊이"에서 **딥 시그널**을 고르면 됩니다. 소리를 켜고, 막마다 저장되니 나눠서 해도 됩니다.

- [ ] 4~6막(유리 도서관, 꿈꾸는 기계, 최초의 기록)이 앞 막의 반복이 아니라 새로운 곳처럼 느껴지는가?
- [ ] 6막까지의 난이도가 어떤가? 너무 쉬운가, 어느 막에서 벽을 느꼈는가? 길어서 지치는 구간이 있는가?
- [ ] **기절**: 벽에 부딪혀 적이 기절할 때 예고가 사라지는 것이 눈에 보이고 시원한가?
- [ ] **궁극기**: 게이지가 찼을 때 시그널 버스트와 동료 궁극기 중 고르는 것이 쉬운가? 컷인의 길이와 세기가 적당한가, 반복되면 거슬리는가?
- [ ] **궁극기 소리**: 동료 11명의 소리가 각자 다르게 들리고 장면에 어울리는가? (어느 동료의 소리가 이상했는지 적어 주세요)
- [ ] **길에서 만나는 동료**: 3막부터 막마다 동료 합류 장면이 나올 수 있습니다. 추적도 +8을 내고 합류시킬지 고민이 되는가?

## 7. 아카이브 — 새로 생긴 것

- [ ] **변칙 조합기**: 접속 설정의 "직접 조합하기"에서 변칙 2~3개를 고릅니다. 일반 루프로 집계되고 오늘의 시드에는 쓸 수 없는데, 이 규칙이 괜찮은가?
- [ ] **업적**: 아카이브 업적 탭의 이름과 설명이 어색하지 않은가? 끝 화면의 한 줄이 조용하면서도 눈에 띄는가?
- [ ] **도감**: 적과 카드 도감을 채우고 싶어지는가?

## 8. 금지 임플란트와 잡음 게이트 — 한 판이 달라지는가

보스를 잡으면 금지 임플란트를 고를 수 있고, 지도의 사건에서 잡음 게이트를 만날 수 있습니다.

- [ ] 금지 임플란트를 고를 때 "이걸로 판을 바꿔 볼까" 하고 고민이 되는가? 뻔한 선택지가 있는가?
- [ ] 임플란트를 든 뒤 실제로 평소와 다르게 플레이하게 되는가? 어떤 것이 가장 재미있었고, 어떤 것이 함정 같았는가?
- [ ] 단점이 억울하지 않고 미리 보이는가?
- [ ] 잡음 게이트에서 체력을 내고 들어갈지 고민이 되는가? 보상이 그 값을 하는가?
- [ ] 여러 판을 해 보니 같은 사건이 덜 반복되는가?

## 9. 듀오 궁극기 — 두 사람의 한 방

사연이 있는 두 동료를 함께 출격시키고 기세를 채우면 합동 궁극기가 나타납니다. 찾은 듀오는 아카이브 도감의 듀오 탭에 기록됩니다.

- [ ] 듀오가 처음 나왔을 때 "이 둘에게 이런 게 있었네" 하는 반가움이 있는가?
- [ ] 어떤 쌍을 출격시킬지 고르는 재미가 생기는가? 듀오를 찾아보고 싶어지는가?
- [ ] 컷인 그림(12장)이 마음에 드는가? 어색한 그림이 있으면 쌍 이름을 적어 주세요.
- [ ] 두 효과음이 이어서 나는 것이 괜찮은가, 전용 소리가 필요한가?
- [ ] 개인 궁극기보다 듀오를 고르고 싶어지는가? 너무 약하거나 강한 쌍이 있는가?

## 외부 테스터에게 물을 다섯 가지 (설문용)

1. 처음 10분 안에 그만두고 싶었던 순간이 있었나요? 언제였나요?
2. 가장 기억에 남는 한 턴(또는 한 장면)은 무엇이었나요?
3. 직접 써 넣은 행동이나 대사에 게임이 제대로 반응했나요? (예 / 아니요 / 안 써 봄)
4. 한 판이 끝난 뒤 바로 다시 시작했나요? 아니라면 이유는?
5. 이 게임을 친구에게 한 문장으로 소개한다면?
