- [ ] **보스 빌드업 → IX 전투 → 엔딩** — 서사 턴 기준 빌드업(레이어당 5턴, 전투 라운드가 진행을 안 잡아먹음)이 충분한가. 보스 노드 도착 시 **먼저 대치 서사+선택지**, 다음 선택에서 실제 IX 전투 발화. 승리→관점 엔딩 / 패배→소거로 **보스 승패가 엔딩을 결정**하고, **tension 100이든 stability 바닥이든 보스 전에 "Journey's End"류 threshold 엔딩이 선점하지 않는가**(라운드3 수정 — 직전 라이브에서 rn10, stab=3으로 전투 없이 종료됐던 케이스).
- [ ] **동료 성장 체감 (라운드3 신규)** — ① 호감도 쌓인 동료(세린 2+)의 전투 HP가 기본(14)보다 높은가; ② 누적 승수 4+ 세이브에서 세린이 글리치 블링크를 쓰는가(업적 킷 업그레이드); ③ `bond` 태그 분(분대 동기화/수호 프로토콜/링크 오버드라이브) 선택 시 동료 스탯/HP에 실반영되는가. ※ UI 배지는 아직 없음 — 전투 로스터 수치로 확인.
- [ ] **전투 보상 실표기** — 승리 loot(드론 스크랩 등)가 인벤토리에 실제 남는가(캐시 클로버 수정). 전투 직후 내러티브 선택을 거쳐도 유지되는가.
- [ ] **린위에 영입+참전** — 린위에 사이드아크 완료 → 이후 전투에 아군 참전(원거리 지원/EMP). 스프라이트 5종 렌더 정상(배경 투명, 포트레이트 일관).
- [ ] **시장 물물교환** — market 노드에서 교환 카드 등장(스크랩 2→nanopatch / 3→stim_shard / 6→mesh_vest), 린위에 상인 연출이 서사에 자연스러운가.
- [ ] **분(Boon)/에코 각인** — 루프 시작+전투 승리 시 1-of-3 분 제안, 루프 시작 시 에코 각인 제안이 뜨고 효과가 체감되는가.
- [ ] **수동 세이브 슬롯 복원** — 세이브 여러 번 = 각각 별도 슬롯, 로드하면 **그 시점으로 실복원**(썸네일·씬 일치). 오토세이브 북마크는 그대로.
- [ ] **BGM 자동 켜짐** — 오프닝 진입 시 BGM 강제 on(과거 세션에서 꺼놨어도).
- [ ] **첫 루프 튜토리얼 파티 + 업적 영입** — 첫 루프에 세린+카이 보장 → IX전 승산 체감. 이후 누적 업적(승수/클리어수/단서)으로 한/수아/태오/린위에 해금 흐름이 자연스러운가.
- [ ] **작전지도 호라이즌 갱신 (구 리스크 재현 확인)** — 진행 중 작전지도의 전방 노드/다음 목적지 전망이 실시간 갱신되는가. 과거 "중반부 호라이즌이 안 바뀐다" 라이브 보고(STATUS Open Risks) — 루트시계 수정 후에도 재현되면 `[!]`+스크린샷.
- [ ] **밸런스 체감** — 분 강도(과/부족), IX 파티 스케일링(소파티 시 호위 드론 감소), 동료 성장 포함 시 과강화 여부, 루프 길이 30~60분(5턴/레이어). 전투 페이싱 정상(같은 접촉 반복·연속 강제전투 없음). **stability 바닥인 채 보스까지 끌려가는 구간의 서사 톤**(붕괴 직전 압박이 느껴지는가 — 라운드3 유예의 트레이드오프).
