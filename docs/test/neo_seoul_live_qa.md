## 플레이 A0 — 전투 P0 판정 (★최우선, 다음 단계 GO/NO-GO 게이트)

> 전투 "버튼 누르고 구경만" 문제를 줄이려고 3가지를 넣었습니다. 새 루프에서 전투를 한 번
> 치르며 아래만 봐 주세요. **이 판정이 다음 큰 전투 개편(무확률·밀기당기기·목표 지키기) 착수
> 여부를 결정합니다** — 그래서 지금 최우선입니다.

- [ ] **1. 적이 뭘 할지 미리 다 보이나?** 적이 칠 타일에 무기 아이콘 + 피해량(예: `⚔ 2d6`)과
  공격자→대상 연결선이 **내 턴 시작 전에** 표시돼야 합니다.
  - 정상: 어느 칸이 위험한지, 맞으면 얼마 아픈지 보고 미리 피하거나 막을 수 있음.
  - 문제: 표시가 안 뜸 · 표시 피해와 실제 피해가 다름 · 연결선이 엉뚱한 대상 → `[!]`.
- [ ] **2. 넓어진 보드(10×7)가 적당한가?** 이동/자리잡기에 여유가 생겼는지.
  - 정상: 텔레그래프 보고 피할 공간이 생겨 "생각하는 맛"이 늚.
  - 문제: 너무 넓어 이동만 하다 턴 끝남(늘어짐) · 너무 좁아 그대로 → `[!]` + 체감 메모.
- [ ] **3. 지형이 읽히나?** 바닥/엄폐물이 그냥 네온 격자보다 전장처럼 보이나.
  - 참고: 지형 타일 아트는 준비 중 — 없어서 **기존 룩(절차 생성)으로 나오면 정상**입니다.
- [ ] **4. ★핵심 판정 — 아직도 "구경"인가?** 대상만 고르면 자동 진행되는 관람 느낌인지,
  아니면 텔레그래프 보고 매 턴 어떻게 움직일지 판단하는 맛이 생겼는지 **한 줄로** 적어 주세요.
  - 이 한 줄이 다음 단계(무확률 결정론 / 밀기·당기기 / 목표 지키기) 착수 여부를 가릅니다.

## 플레이 A — 새 루프 1판, 폰으로 (KO, 20~30분) ★최우선

> 새 캐릭터로 시작해서 평소처럼 플레이하면서, 아래 6가지만 신경 쓰면 됩니다.
> 폰으로 하면 모바일 항목까지 한 번에 커버됩니다 (PC로 해도 1~4는 판정 가능).

- [x] **1. 세린이 멋대로 나오나?** 2회차 이상 루프(변형 오프닝)에서는 세린을 다시 만나기 전까지
  세린이 **어디에도** 나오면 안 됩니다 — 이야기 속 등장·인물 사진·전투 참전 전부.
  - 정상: 이번 루프의 동료(한/카이 등)만 나옴. 세린은 다시 만나는 장면 후에만 등장.
  - 문제: 안 만났는데 세린이 말 걸거나, 사진이 뜨거나, 전투에 끼어듦 → `[!]` + 몇 턴째였는지.
  - 참고: **맨 첫 루프(튜토리얼)에선 세린이 나오는 게 정상**입니다.
- [x] **2. 인물 사진(CHARACTER 패널)이 제때 바뀌나?** 규칙: **그 인물이 실제로 말할 때만** 사진이 뜹니다.
  - 정상: 아무도 대사 없는 장면 = 내 캐릭터 사진 유지 · 동료가 말하는 장면 = 그 동료 사진.
  - 문제 ①: 이름만 언급됐는데(문서·기억 얘기) 사진이 바뀜 → `[!]`.
  - 문제 ②: 분명히 대사를 하는데 사진이 안 뜸 → `[!]` (따옴표 없는 간접화법 장면 특히 주의).
  - 예외: **야시장 흥정 중엔 린위에 사진이 항상 떠 있는 게 정상**입니다.
- [x] **3. 선택지가 바로 뜨나?** 글이 다 나오면 선택지가 **즉시** 떠야 하고, 장면 이미지는 뒤따라 나타납니다.
  - 문제: 선택지 없이 몇 분씩 멈춤(예전 버그) → `[!]`.
- [x] **4. 스탯 이름이 일치하나?** 선택지 태그(지능/민첩…)와 캐릭터 시트·부스트 카드·보상 설명이
  전부 **근력/지능/매력/민첩/관측**으로 통일 — 연산/공명/반사/지각이 보이면 `[!]`.
  (단, "반사 오버클럭·차가운 연산" 같은 아이템/스킬 고유명은 그대로가 정상.)
- [ ] **5. (폰) 스크롤이 편한가?**
  - 글 나오는 중에 스크롤해도 안 버벅이나 · 위로 올려 읽는 중에 바닥으로 안 끌려가나.
  - 전투 화면: 보드 위에 손가락 대고 위아래로 밀면 페이지가 스크롤되나 (보드는 좌우만).
  - 글자가 읽기 편한가(딱딱한 고정폭 아님) · 헤더 사라지고 ⋯ 버튼이 엄지로 눌리나 · 탭 4개(이야기/도감/인물/스킬)가 안 깨지나.
- [ ] **6. 읽으면서 걸리는 것**: 막 목표가 장면과 어긋남 · 만나기도 전에 이름(카이)이 튀어나옴 ·
  "순찰로=안전"이라 해놓고 전투 나옴(이제 정직하게 표기돼야 정상) · 내면 독백이 선택지와 무관하게 남발
  (스탯 체크 선택지가 있는 턴에만 떠야 정상) → 있으면 `[!]`.
