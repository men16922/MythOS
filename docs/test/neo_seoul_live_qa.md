## 1. ★서사 모델 교체 판정 (A/B) — 이번 배포의 핵심 승부처

> 비용을 절반으로 줄이기 위해 **일반 턴은 가벼운 모델**, **중요한 장면(오프닝·주요 분기·동료
> 컷신·보스 직전·엔딩)은 기존 상위 모델**로 나눠 쓰도록 바꿨습니다. 상위 모델이 유지되는
> 장면은 품질이 그대로여야 하고, 관건은 **일반 턴이 눈에 띄게 나빠졌는지**입니다.
> 한두 루프 플레이 후 아래 다섯 줄만 판정해 주세요. 유지/롤백 결정에 그대로 씁니다(롤백은 즉시 가능).

- [ ] **일반 턴 문장이 밋밋/반복적인가?** 탐사·이동·일상 교전 턴의 프로즈가 확 싱거워졌는지.
  - 정상: 이전과 구분이 잘 안 됨. 문제: 문장이 짧고 뻔해짐 · 같은 표현 반복 → `[!]`.
- [ ] **중요 장면 품질은 그대로인가?** 오프닝·컷신·보스 직전·엔딩이 기존 수준인지.
- [ ] **이름/상태/언어 오류가 늘었나?** 인물 이름 틀림 · 한/영 섞임 · 스탯과 안 맞는 서술.
- [ ] **턴 간 연속성이 무너지나?** 직전 장면 참조가 끊기거나 방금 한 일을 잊은 듯한 턴.
- [ ] **체감 속도**: 일반 턴이 더 빨라졌으면 보너스 (같거나 빨라야 정상).

## 2. ★(폰 실기기) 세로 전투 — 액션 독 + 턴 순서 스트립 (신규)

> "스킬/공격 하나 쓰려면 자꾸 스크롤해야 한다"를 고쳤습니다: 세로로 들면 **행동 콘솔이 화면
> 하단에 고정 시트로 도킹**되고(보드는 위에 그대로), 보드 위에는 **턴 순서 스트립**(초상 칩 +
> 기절/공격/이동 배지)이 새로 붙었습니다. 에뮬레이터로는 통과했고 **실물 폰 확인만 남았습니다.**

- [ ] **엄지가 닿는가**: 전투 중 스크롤 없이 보드와 TARGETS/ACTIONS/SKILLS가 **한 화면**에 보이고,
  하단 독 안에서 바로 탭해 턴이 진행되는지.
  - 문제: 독이 안 뜨고 예전처럼 스크롤 지옥 · 독이 보드를 너무 가림 → `[!]`.
- [ ] **독 높이감**: 독(최대 화면의 4할)이 답답하거나, 반대로 항목이 너무 잘려 스크롤이 과한지.
- [ ] **브라우저 주소창/노치**: 주소창이 내려오거나 노치 있는 폰에서 독이 가려지거나 떠 있지 않은지.
- [ ] **턴 순서 스트립 가독성**: 보드 위 초상 칩 줄이 폰 폭에서 읽히는지 · 지금 누구 턴인지 보이는지.
- [ ] **(겸사) 작전지도 드래그**: 지도를 손가락으로 끌면 움직이는지.
- [ ] **(겸사) 스크롤 체감**: 글 나오는 중 스크롤 버벅임 · 위로 읽는 중 바닥으로 끌려가는 문제가 남았는지.

  - 정상: 장면의 시선·긴장 흐름·엔딩 분위기가 두 판에서 **다르게** 흘러감.
  - 문제: 바꿔도 거의 똑같음(둔함) 또는 몇 번 안 골랐는데 과하게 쏠림(예민함) → `[!]` + 체감 메모.
- [ ] 선택지의 `(민첩)` 같은 **스탯 태그**가 체크처럼 보이는데 실제 효과가 있는지 없는지 헷갈렸다면
  그 느낌도 메모 (실효 부여 vs 표기 변경 결정에 씁니다).

## 5. 이미지 캐릭터 일관성 (실루프)

  - 정상: 같은 인물로 읽힘 · 그림체가 장면끼리 크게 안 튐.
  - 문제: 턴마다 다른 사람 · 성별/외형 바뀜 → `[!]` + 누가/몇 턴째였는지 스크린샷.
- [ ] **이미지가 제때 나오나?** 이미지 없는 턴이 연달아 나오면 `[!]` + 대략 빈도("10턴 중 3턴"이면 충분).

## 6. 동료 영입 (여러 루프에 걸쳐)

- [ ] **각 동료가 실제로 파티에 합류하나?** 작전지도의 만남 앵커(한=러너의 지름길 · 수아=잠금 너머 ·
  태오=오래된 상처 · 린위에=은밀한 의뢰)를 방문한 뒤, **다음 전투에서 내가 직접 조종하는 파티원**으로
  참전해야 합니다. (루프당 사이드 앵커 최대 2개 → 여러 루프로 나눠 확인.)
  - 문제: 방문했는데 파티에 안 들어옴 · 대화만 되고 전투에서 못 씀 → `[!]` + 어느 동료였는지.
- [ ] **파티가 커지면 밸런스가 무너지나?** 3~4명이면 적이 손도 못 쓰고 끝나는지 체감.
