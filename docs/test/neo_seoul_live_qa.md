## 플레이 A — 전투 P0 판정 (다음 단계 GO/NO-GO 게이트)

  - 문제: 사거리 안인데도 안 뜸 · 표시 피해와 실제가 다름 · 연결선이 엉뚱한 대상 → `[!]`.
- [x] **2. 지형/타일이 깔끔하고 읽히나?** 바닥은 **어두운 지면**, 엄폐물은 **프롭(크레이트/기둥)**,
  솟은 칸은 **높이감**으로 구분돼야 합니다. 배지(▲고도/🛡엄폐)는 **호버하거나 탭한 칸에만** 떠야 합니다.
  - 정상: 보드가 한눈에 정리돼 보이고, 어떤 칸이 엄폐/고도인지 그림으로 읽힘.

- [x] **3. 회복(패치 프로토콜)이 작동하나?** echo_collector로 시작하면 나노패치 2개를 갖고 시작합니다.

  - 문제: 방문했는데 여전히 파티에 안 들어옴 · 대화만 되고 전투에서 못 씀 → `[!]` + 어느 동료였는지.
