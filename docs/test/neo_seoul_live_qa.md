"화면에 실제로 뜨나"까지 확인한 것은 **✅**로 표시했습니다 — **직접 안 봐도 됩니다.**
**🙋 가 붙은 것만 직접 플레이하며 확인**하시면 됩니다.

여기 남긴 건 사람이 직접 해봐야 아는 것들입니다. 기계 검증(unittest·E2E)은 이미 통과했고,
그 위에 이번 로컬 점검으로 렌더/적용까지 확인된 것은 ✅, 여전히 **체감·직접 조작·실루프**가 필요한
것은 🙋 로 갈랐습니다.

## 이번 로컬 점검에서 ✅ 된 것 (직접 스킵 가능)

- 스킬/아이템 버튼 아이콘(글자 타일 없음 · 소모품 썸네일 있음) · 전장 배경 색조(거리 = 푸른빛)

- 시스템 해킹/EMP = **기절 적용** + 로스터 기절 배지 + 스킬 컷인 · 공격 컷인(즉시 + 피해 숫자)

나머지 🙋 항목은 아래 본문에서 줄마다 표시했습니다.

## 쓰는 법 (3줄)

1. **A → B → C → D** 순서대로, 한 번에 하나씩. 급하면 A만 해도 최우선은 커버됩니다.
2. 각 항목은 **"이러면 정상 / 이러면 문제"**. 문제면 그 줄에 `[!]` + 한 줄 메모(+가능하면 스크린샷).
3. 표기: `[ ]` 아직 안 봄 · `[~]` 부분 확인 · `[x]` 확인 끝 · `[!]` 문제 발견 · **✅ 자동 점검 완료(직접 스킵)** · **🙋 직접 확인 필요**.

- [ ] **각 동료가 실제로 파티에 합류하나?** 작전지도에서 아래 만남 앵커를 방문한 뒤, **다음 전투**에서
  그 동료가 **내가 직접 명령하는 파티원**으로 참전해야 합니다 (AI가 알아서 싸우는 임시 아군이 아니라).
  - 한 = **러너의 지름길** · 수아 = **잠금 너머** · 태오 = **오래된 상처** · 린위에 = **은밀한 의뢰**.
  - 정상: 앵커 방문 → 다음 전투에서 조종 가능한 파티원으로 붙음 · 인물 탭에서 "파티" 표기.
  - 문제: 방문했는데 여전히 파티에 안 들어옴 · 대화만 되고 전투에서 못 씀 → `[!]` + 어느 동료였는지.
  - 참고: 세린(첫 루프 시작 동료)·카이(각성 루트)는 원래부터 정상. 승리 화면 라인업에 린위에가
    안 나오던 것도 고쳤으니, **4인 파티 승리 화면에 전원이 보이는지** 겸사 확인.
- [ ] **파티가 커지면 밸런스가 무너지나?** 여러 동료를 모은 뒤 전투가 **너무 쉬워지지** 않는지 체감.
  - 문제: 파티 3~4명이면 적이 손도 못 쓰고 끝남 → `[!]` + 몇 명일 때였는지.

## 플레이 C — 스타일 갈라치기 2판 (밸런스, 각 ~20분)

> 선택이 이야기를 실제로 바꾸는지 확인하는 새 시스템이 켜졌습니다. **같은 캐릭터로 2판**을
> 서로 다르게 플레이해 보세요.

- [ ] 1판은 **사람 돕기/개입** 위주로, 1판은 **안전/증거 수집** 위주로 선택.
  - 정상: 장면의 시선·긴장 흐름·엔딩 분위기가 두 판에서 **다르게** 흘러감.
  - 문제: 스타일을 바꿔도 거의 똑같음(밋밋) 또는 몇 번 안 골랐는데 과하게 쏠림 → `[!]` + 체감 메모
    (민감도 조절 가능하니 "너무 둔함/너무 예민함"이면 충분).
- [ ] 선택지의 `(민첩)` 같은 스탯 태그가 **체크처럼 보이는데 실제 효과가 있는지 없는지** 헷갈렸다면
  그 느낌도 메모 (실효 부여 vs 표기 변경 결정에 씀).

## 플레이 D — 완주 1판 (30~60분, 전투·시장·보스·엔딩)

> 처음부터 엔딩까지 한 판. 세부 항목보다 **끊기지 않고 재밌나**가 핵심 질문입니다.

- [ ] **페이스**: 루트 진행 ~15-20분에 늘어짐 없나 · 보스 직전 휴식이 "결전 전 정비"로 읽히나.
- [ ] **전투**: 전투 발생→보상→이야기 복귀가 자연스럽나 · 다운된 동료 복귀/부활 ·
  동료 성장(호감도/장비)이 체감되나 · 타일 정보 3줄(HP/의도/엄폐)이 판단에 도움되나.
- [ ] **시장/아이템**: 아이템이 남발되지 않나 · 인벤토리/장착이 RPG답게 읽히나 · **승리 보상 이름이
  이제 한글로** 뜨나 (전엔 `drone_scrap` 같은 코드가 그대로 보였음).
- [ ] **동료 컷신**: 안전 경유 장면에서 **한 번만** 뜨고, 이미지와 대본이 맞고, 다음 장면 복귀 정상.
- [ ] **엔딩**: 숫자가 아닌 이야기로 납득되나 · 구한 것/잃은 것이 남나 · 다음 루프 예고가 다시 하고 싶게 하나.
- [ ] **총평**: 30-60분 안 끊기고 기억나는 장면 3개 이상? 밸런스 이상(분 강도·IX 스케일·동료 과강화·전투
  페이싱)이 있으면 `[!]` + 제안값.

## 남은 서사/모바일 체크 (플레이 A~D 중 아무 때나)

- [ ] **선택지가 항상 도착하나 (고친 부분)**: 이미지가 늦는 턴이나 폰을 잠깐 껐다 켠 뒤에도 선택지가
  결국 떠야 합니다 (전에 가끔 안 오던 문제를 고침).
  - 문제: 30초 넘게 선택지가 안 와서 새로고침해야 진행됨 → `[!]` + 어떤 상황이었는지.
- [ ] **읽으면서 걸리는 것**: 막 목표가 장면과 어긋남 · 만나기도 전에 이름(카이)이 튀어나옴 ·
  "순찰로=안전"이라 해놓고 전투 나옴(이제 정직하게 표기돼야 정상) · 내면 독백이 선택지와 무관하게 남발
  (스탯 체크 선택지가 있는 턴에만 떠야 정상, "내면의 목소리" 라벨이 붙고 인물 초상으로 오인되지 않아야 정상) → 있으면 `[!]`.
- [ ] **(폰) 세로로 전투가 되나 (고친 부분)**: 폰을 세로로 든 채 전투에서 아무 데나 탭하면 **행동
  콘솔이 먼저** 잡혀서, 가로로 돌리지 않아도 턴을 진행할 수 있어야 합니다.
  - 문제: 세로에선 버튼이 가려지거나 스크롤 지옥이라 사실상 못 함 → `[!]`.
- [ ] **(폰) 작전지도 드래그 (고친 부분)**: 작전지도를 손가락으로 끌면 지도가 움직여야 합니다.
- [ ] **(폰) 남은 스크롤 체감**: 글 나오는 중 스크롤해도 안 버벅이나 · 위로 올려 읽는 중 바닥으로 안 끌려가나 ·
  전투 보드 위에서 위아래로 밀면 페이지가 스크롤되나(보드는 좌우만).
