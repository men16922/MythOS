## 발견

1. **[measured]** 이 워크로드는 prefill-heavy다 (입력:출력 = 30.2:1).
   - 근거: 입력 중앙값 7098 토큰 vs 출력 중앙값 235 토큰, gemma4:latest의 실제 토크나이저로 9턴 측정.
2. **[measured]** 연속 턴이 프롬프트의 67.7%를 리터럴 프리픽스로 공유한다.
   - 근거: 8개 연속 쌍, 범위 61.0–80.1%.
3. **[measured]** 이 실행에서 생성의 44%가 저하됐다 (빈 응답 3, 오류 1).
   - 근거: 트레이스 레코드의 response 길이 0 및 error 필드.
